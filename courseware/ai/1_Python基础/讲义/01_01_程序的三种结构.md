# 一、概念与原理

## 1. 程序的三种基本结构

几乎所有程序都由这三种结构组合而成：

| 结构 | 含义 | Python 语法 | 本门课首次出现 |
|---|---|---|---|
| **顺序** | 从上到下逐行执行 | 默认行为 | 本章 |
| **分支** | 根据条件走不同的路 | `if / elif / else` | 本章（1.2 细讲） |
| **循环** | 重复执行某段代码 | `while`、`for` | 1.3 |

猜数字是能同时用上三种结构的最小程序：读输入（顺序）→ 比较大小（分支）→ 没猜中就再来（循环）。这也是它被选为全课载体的原因。

## 2. 输出：`print()`

```python
print("你好")
print("答案是", 42)          # 多个参数用空格隔开
print("答案是", 42, sep="")   # sep 控制分隔符
```

```text
你好
答案是 42
答案是42
```

`print()` 的更多参数在第 1.4 章讲。现在只需要会用它把东西显示出来。

## 3. 输入：`input()`

```python
name = input("请输入你的名字：")
```

三个要点：

**一、括号里的字符串是提示语**，会原样打印，**不会自动换行**。所以提示语末尾习惯加一个冒号或空格，让用户的输入不紧贴着文字。

**二、它会暂停程序**，一直等到用户按下回车才继续。这种「等待外部输入」的行为叫**阻塞**。

**三、返回值永远是字符串。** 这是最容易忘的一点，单独展开讲。

## 4. ⚠️ `input()` 返回的永远是字符串

用户输入了 `18`，你拿到的不是数字 18，是**字符串** `"18"`。

```python
age = input("年龄：")    # 用户输入 18
```

配套示例模拟了这个场景，看看对它做运算会怎样：

```text
1. input() 拿到的永远是字符串
   type(age) = <class 'str'>
   age > 10         → TypeError: '>' not supported between instances of 'str' and 'int'
   age + 1          → TypeError: can only concatenate str (not "int") to str
   age * 3          → '181818'
   int(age) > 10    → True
```

前两行报错，至少你会知道出了问题。**真正危险的是第三行**：

```python
age * 3      # 你以为是 54，实际是 '181818'
```

**它不报错。** 字符串乘以整数是合法的——意思是「重复 3 次」。程序会带着一个错误的结果继续往下跑，直到很远的地方才露出马脚。

> **规律**：凡是从外部来的数据（键盘、文件、网络、环境变量），先当成字符串，
> 确认格式之后再转换。这条规律在第 4 章读文件、第 5 章调 API、第 6 章读配置时会反复出现。

## 5. 字符串比较：字典序，不是数值

```text
2. 字符串比较是按字符逐个比，不是按数值
   '9' > '10'   → True      ← 比的是第一个字符 '9' 和 '1'
   9 > 10       → False
```

**两个字符串比大小时，Python 从第一个字符开始逐个比较字符的编码**，第一个不同的字符决定结果。`'9'` 的编码比 `'1'` 大，所以 `"9" > "10"` 成立，后面的 `'0'` 根本没参与比较。

这和查字典的规则一样，所以叫**字典序**。

| 比较 | 结果 | 原因 |
|---|---|---|
| `"apple" < "banana"` | `True` | `a` < `b` |
| `"9" > "10"` | `True` | `9` > `1` |
| `"100" < "99"` | `True` | `1` < `9` |
| `9 > 10` | `False` | 数值比较 |

**如果你忘了转换类型，又恰好比的是两个字符串，程序不会报错，只会给出错误的结果。** 这比 `TypeError` 难发现得多。

## 6. 类型与类型转换

Python 是**动态类型**语言：变量不需要声明类型，类型由当前存的值决定。

```python
x = 10        # 现在 x 是 int
x = "hello"   # 现在 x 是 str，完全合法
type(x)       # <class 'str'>
```

常用的转换函数：

| 函数 | 作用 | 失败时 |
|---|---|---|
| `int(x)` | 转整数 | 抛 `ValueError` |
| `float(x)` | 转浮点数 | 抛 `ValueError` |
| `str(x)` | 转字符串 | 基本不会失败 |
| `bool(x)` | 转布尔值 | 不会失败（规则在 1.2） |

**转换失败会抛异常，不是返回 `None`。** 怎么处理异常是第 1.5 章的内容。

### `int()` 的边界：这张表值得记住

```text
3. int() / float() 的转换边界
   int("42")        → 42
   int("abc")       → ValueError: invalid literal for int() with base 10: 'abc'
   int("")          → ValueError: invalid literal for int() with base 10: ''
   int("3.14")      → ValueError: invalid literal for int() with base 10: '3.14'
   int(3.99)        → 3
   int(-3.99)       → -3
   int(" 42 ")      → 42
   int("+7")        → 7
   int("-7")        → -7
   int("1_000")     → 1000
   int("４２")        → 42
   float("3.14")    → 3.14
   float("1e3")     → 1000.0
   float("abc")     → ValueError: could not convert string to float: 'abc'
```

几个反直觉的地方：

| 现象 | 解释 |
|---|---|
| `int("3.14")` 报错，`int(3.99)` 不报错 | 前者是**解析字符串**，格式必须是整数；后者是**数值转换**，直接丢掉小数 |
| `int(3.99)` 是 `3` 不是 `4` | **截断**，不是四舍五入 |
| `int(-3.99)` 是 `-3` 不是 `-4` | 截断是**向零取整**，不是向下取整 |
| `int(" 42 ")` 成功 | `int()` 会自己忽略首尾空白 |
| `int("1_000")` 成功 | Python 允许在数字里写下划线分隔，方便阅读 |
| `int("４２")` 成功 | 全角数字也认 |

**最后三条说明 `int()` 比你想的宽容。** 第 1.2 章会遇到一个后果：你自己写的「检查是不是整数」的逻辑，很容易和 `int()` 的真实规则对不上。

## 7. 第一版猜数字

把上面的东西拼起来：

```python
TARGET = 10

def check_num(guess: int, target: int) -> str:
    if guess == target:
        return "正确"
    elif guess < target:
        return "小了"
    else:
        return "大了"

guess = int(input("猜一个数字： "))
print(check_num(guess, TARGET))
```

三种结构用到了两种：顺序（读输入 → 转换 → 判断 → 输出）和分支（三路判断）。

**关于 `def`**：`check_num` 是一个函数。`def` 的完整语法在第 1.6 章讲，现在只需要知道：

- `check_num(3, 10)` 会得到 `"小了"`
- `return` 后面的值就是函数的结果

**为什么要把判断写成函数，而且是 `return` 而不是直接 `print`？** 第 2.1 章会给出答案。先记住这个形状——它是整门课第一个被反复测试的函数。

### 跑一下

```powershell
python -m m01_basics.ch01_01_example play
```

输入 `3`，看到 `小了`。再跑一次，**输入 `abc`**：

```text
Traceback (most recent call last):
  ...
    guess = int(input(f"猜一个数字（答案是 {TARGET}，测试用）： "))
            ~~~^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
ValueError: invalid literal for int() with base 10: 'abc'
```

按第 0.1 章讲的方法**从下往上读**：

| 看哪里 | 得到什么 |
|---|---|
| 最后一行 | `ValueError`：值不对。`'abc'` 不是合法的十进制整数（`base 10`） |
| 倒数第二组 | 出错在 `int(input(...))` 这一行，`~~~^^^` 指出是 `int(...)` 这个调用 |

**这个崩溃是这一版的已知缺陷。** 修它有两种思路：

- **先检查再转换**：确认字符串长得像整数，才调用 `int()` → 第 1.2 章
- **直接转换，失败了再处理** → 第 1.5 章

两种思路各有问题，到时候对比着看。

## 8. 命名与代码风格：PEP 8 基础

Python 有官方风格指南 **PEP 8**。现在就该遵守的几条：

| 规则 | ✓ | ✗ |
|---|---|---|
| 缩进用 4 个空格 | `····return x` | Tab |
| 变量、函数名小写加下划线 | `input_num`、`check_num` | `inputNum`、`InputNum` |
| 常量全大写 | `TARGET = 10` | `target = 10`（如果它不会变） |
| 运算符两边加空格 | `a = 1`、`x > 10` | `a=1`、`x>10` |
| 逗号后面加空格 | `f(a, b)` | `f(a,b)` |

**名字要表达含义。** `guess` 比 `n` 好，`TARGET` 比 `t` 好。

> **常量**（不会变的值）全大写，是给读代码的人的信号：「这个值别改」。
> Python 不会真的阻止你修改它，这只是约定。

风格不影响程序能不能跑，但影响**别人和三个月后的你能不能快速读懂**。第 0.2 章配好的 `ruff` 会自动检查其中大部分：

```powershell
ruff check .
```

`pyproject.toml` 里开启的 `N` 规则组就是 PEP 8 的命名规范（`N` = naming）。

## 9. 注释

```python
# 单行注释：井号后面的内容都会被忽略

TARGET = 10  # 行尾注释：前面至少两个空格

def check_num(guess: int, target: int) -> str:
    """文档字符串：三引号，写在函数第一行，说明这个函数做什么。"""
```

**注释写「为什么」，不写「做什么」。**

```python
# ✗ 复述代码
x = x + 1   # x 加 1

# ✓ 说明原因
attempts = attempts + 1   # 非法输入不计次，所以只在转换成功后才加
```

代码本身已经说明了「做什么」。注释的价值在于代码里看不出来的东西：为什么这样写、为什么不那样写、有什么坑。

# 三、常见错误

| # | 错误 | 表现 | 怎么避免 |
|---|---|---|---|
| **1** | **忘记转换 `input()` 的结果** | `TypeError: '>' not supported between instances of 'str' and 'int'` | 拿到外部输入先确认类型 |
| **2** | **字符串运算「成功」了** | `"18" * 3` 得到 `'181818'`，不报错 | 同上；对可疑结果打印 `type()` |
| **3** | **字符串比大小** | `"9" > "10"` 为 `True`，排序结果错乱 | 比较前确认两边都是数字 |
| **4** | **以为 `int()` 会四舍五入** | `int(3.99)` 得到 `3` | 要四舍五入用 `round()` |
| **5** | **`int()` 直接转带小数点的字符串** | `int("3.14")` 抛 `ValueError` | 先 `float()` 再 `int()`，或者明确要求输入整数 |

**第 2、3 条比第 1 条危险**：第 1 条会报错，你至少知道出了问题；第 2、3 条不报错，程序带着错误的结果继续跑。

# 四、本章小结

```text
三种结构：顺序 / 分支 / 循环
        ↓
print() 输出，input() 输入
        ↓
⚠️ input() 永远返回 str
   ├─ 运算会报错（TypeError）       ← 至少你知道
   ├─ 乘法会「成功」（'181818'）     ← 不报错，更危险
   └─ 比大小按字典序（'9' > '10'）  ← 不报错，更危险
        ↓
int() 转换：比你想的宽容（空格、正负号、下划线、全角都认）
        ↓
第一版猜数字：能跑，但输入 abc 会崩  →  1.2 和 1.5 用两种思路修
```

一句话总结：**从外部来的数据，在你确认之前都只是字符串。** 不报错的错误结果，比报错危险得多。
