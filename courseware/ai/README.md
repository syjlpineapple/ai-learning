# AI 应用开发

> 本文件由 `.vitepress/lessons.ts` 自动生成，不要手改：改课表请改 lessons.ts，启动一次网站就会更新。

从一个猜数字程序开始，一路做到带 RAG、Agent、数据库和部署的 AI 应用。按当时定下的 90 天路线（11-17 调整版）走，每天约 45 分钟。

## 怎么学

- **一天一个文件**，放在对应阶段的文件夹里，文件名前面是编号，按文件名排序就是学习顺序。
- **只看源文件也能学**：在 Kiro / VS Code 里打开一个 `.md`，按 `Ctrl+Shift+V` 看排版后的预览，公式、表格、折叠的小测答案都能正常显示，指向代码的链接点了直接打开文件。
- **每天的顺序**：讲概念 → 演示（代码和真实输出）→ 今天的作业 → 小测。
- **作业写在** 仓库根目录的 `dailypractice/DayNN/`（和原来一样）。写完把运行输出发给我（或者说一声「Day 23 做完了」），讲评会追加到那一天的文件末尾。
- 想要进度条、打勾和全文搜索，就打开网站：在 `courseware/` 下运行 `npm run docs:dev`。
