# 第 31 课：正则化（Regularization）

上一课你的实验结果是：训练集 100%，测试集 16.7%。模型在学过的数据上很好，面对新评论很差。

今天学一种常用的应对方法：**正则化**。这一课分两段：先学 L2，用它做一组实验；再认识 L1，和 L2 对比。

## 一、正则化是什么

想象你在带一个学生：

- 不加约束：学生拼命记住每一道练习题，连题目里的细节都背下来。
- 加上约束：不许只靠死记硬背，要学更稳定、更有代表性的规律。

在机器学习里，正则化就是：

**给模型加一个约束，不让参数变得太大，从而降低它过度拟合训练数据的风险。**

正则化不保证准确率一定提高，它是在控制模型的复杂程度。

## 二、先认识模型参数

逻辑回归会给每个特征（每个词）学一个**权重**。比如（示意）：

| 特征词语 | 模型权重 |
|---|---:|
| 好用 | 2.5 |
| 优秀 | 1.8 |
| 糟糕 | -2.2 |
| 很差 | -3.0 |

权重为正，把预测往好评推；为负，往差评推。**绝对值越大，这个词对结果的影响越大。**

如果模型为了把少量训练数据全部分对，学出很多特别大的权重，它就可能变得过于复杂。正则化就是对权重加以约束。

## 三、L2 正则化

常见的正则化有两种：

- **L1**：倾向于让一部分权重直接变成 0。
- **L2**：倾向于让权重整体变小，但通常不会变成 0。

先学 L2，它是逻辑回归里最常用的。可以用一个简化的公式理解：

$$
\text{总损失}=\text{原始损失}+\lambda\sum w_i^2
$$

- 原始损失：模型预测错了产生的损失，第 6 课学过
- $w_i$：每个特征的权重
- $\lambda$：正则化强度，越大，对大权重罚得越狠

意思是：模型想把损失降下来，现在不光要预测准，还得让权重的平方和小。原来把某个权重拉到 10 没有代价，现在要多付 $100\lambda$。

还有一点：**`LogisticRegression` 默认就带着 L2 正则化。** 你之前训练的模型并不是「没有正则化」，今天要做的是**调整它的强度**。

## 四、参数 C：控制正则化强度

scikit-learn 的逻辑回归用参数 `C` 控制强度：

| C | 正则化强度 |
|---:|---|
| 10 | 较弱 |
| 1 | 默认 |
| 0.1 | 较强 |
| 0.01 | 更强 |

**C 越小，正则化越强；C 越大，正则化越弱。** 它和上面的 $\lambda$ 是反过来的。可以把 C 理解成「给模型的自由度」：C 大，权重想多大就多大；C 小，管得严。

## 五、实战：调整正则化强度

保留数据准备部分（从 `train_test_split` 到 `x_train`、`x_test`），把训练部分换成：

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

C_values = [10, 1, 0.1, 0.01]

for c in C_values:

    model = LogisticRegression(C=c, max_iter=1000)
    model.fit(x_train, y_train)

    train_pred = model.predict(x_train)
    y_pred = model.predict(x_test)

    train_acc = accuracy_score(y_train, train_pred)
    test_acc = accuracy_score(y_test, y_pred)

    # 计算模型权重的整体大小
    weight_norm = np.linalg.norm(model.coef_)

    print("C参数：", c)
    print("训练集准确率：", train_acc)
    print("测试集准确率：", test_acc)
    print("权重整体大小：", weight_norm)
    print("--------------------------")
```

新加的一行：

```python
weight_norm = np.linalg.norm(model.coef_)
```

`model.coef_` 是所有权重，`np.linalg.norm` 算的是它们组成的向量的长度，第 18 课算余弦时用过。用一个数概括「权重整体有多大」，就能看出正则化有没有起作用。

你跑出来的结果：

| C | 训练准确率 | 测试准确率 | 权重整体大小 |
|---:|---:|---:|---:|
| 10 | 1.0 | 0.1667 | 6.9215 |
| 1 | 1.0 | 0.1667 | 1.4080 |
| 0.1 | 1.0 | 0.1667 | 0.1633 |
| 0.01 | 1.0 | 0.1667 | 0.0166 |

权重从 6.92 一路降到 0.0166，正则化确实起作用了。可两个准确率一点都没变。为什么？

## 六、参数变了，判断不一定变

要分清两件事：

1. **模型参数变了**：内部的权重改变了。
2. **预测结果变了**：某条评论的判断从 0 变成 1，或者从 1 变成 0。

这两件事不是一回事。在循环里再加几行，看看每条测试评论的好评概率：

```python
    positive_index = list(model.classes_).index(1)
    probabilities = model.predict_proba(x_test)[:, positive_index]

    print("预测标签：", y_pred)
    print("好评概率：", np.round(probabilities, 4))
```

### 背后的数学

逻辑回归用 **Sigmoid 函数**把模型算出的分数变成概率：

$$
P(y=1)=\frac{1}{1+e^{-z}},\qquad z=w_1x_1+w_2x_2+\cdots+b
$$

- $w$：权重，$x$：特征，$b$：偏置
- $z$：模型算出来的分数。$z=0$ 时概率正好是 0.5

权重越接近 0，$z$ 就越接近 0，概率就越接近 0.5。你的实验看到的就是这个。

我又把 C 继续往下压到 0.0001、0.00001、0.000001，权重整体大小每次正好缩小到十分之一，预测标签还是 `[1 0 1 0 1 1]`，训练集准确率还是 1.0。原因是 C 很小时，所有权重是**按同一个比例**缩小的，$z$ 的正负号不会变，而预测只看 $z$ 是正还是负。**L2 在这里调的是模型有多自信，不是它的判断。**

## 七、L1 与 L2 对比

再认识 L1。两者都在约束权重，方式不同：

- **L1（Lasso）**：倾向于让部分权重**直接变成 0**，相当于这些特征退出模型。比如 `[2.5, 1.8, 0.0, -3.0, 0.0]`。
- **L2（Ridge）**：倾向于让权重**整体变小**，一般不会变成 0。比如 `[0.8, 0.5, 0.2, -0.9, 0.1]`。

可以这样记：L1 可能让一部分特征出局；L2 让模型别太依赖某几个特征。

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 当时写的是 penalty="l1" / penalty="l2"。仓库里装的 scikit-learn 1.9 已经把 penalty 标为弃用，
# 会报 FutureWarning；换成 l1_ratio=1（L1）、l1_ratio=0（L2），效果相同
settings = {"l1": 1, "l2": 0}

for name, ratio in settings.items():

    model = LogisticRegression(
        l1_ratio=ratio,
        C=1,
        solver="liblinear",
        max_iter=1000
    )
    model.fit(x_train, y_train)

    train_acc = accuracy_score(y_train, model.predict(x_train))
    test_acc = accuracy_score(y_test, model.predict(x_test))

    weights = model.coef_[0]
    non_zero_count = np.sum(~np.isclose(weights, 0))

    print("正则化类型：", name)
    print("训练集准确率：", train_acc)
    print("测试集准确率：", test_acc)
    print("非零权重数量：", non_zero_count, "/", len(weights))
    print("权重整体大小：", np.linalg.norm(weights))
    print("--------------------------")
```

两个新东西：

- `solver="liblinear"`：默认的求解器 `lbfgs` 不支持 L1，用它会直接报错 `Solver lbfgs supports only 'l2' or None penalties`。`liblinear` 两种都支持。
- `np.sum(~np.isclose(weights, 0))`：`np.isclose(weights, 0)` 判断每个权重是不是接近 0，`~` 取反，`np.sum` 数一数有几个不是 0。比如 `[2.0, 0.0, -1.0, 0.0, 3.0]` 的结果是 3。

这个对比实验当时没有跑，我补跑了一遍：

```text

训练集准确率： 0.5
测试集准确率： 0.5
非零权重数量： 0 / 37

--------------------------
正则化类型： l2

```

> 注意：L1 那一组，37 个权重全被压成 0，训练集和测试集都是 0.5，这才是**欠拟合**真正的样子：两边都差。同一个 `C=1`，对 L2 很温和，对 L1 却是毁灭性的。
<details>
<summary>为什么</summary>

权重全是 0，模型对任何输入都给同一个答案，在好评差评各半的数据上就是 0.5。原因是 TF-IDF 的特征值本来就小，每个词提供的那点收益顶不住 L1 的惩罚。C 放宽到 10，L1 才留下 18 个非零权重。L1 和 L2 不是强弱之分，是机制不同。

</details>

## 八、小测

**1.** 在 `LogisticRegression` 中，如果希望增强 L2 正则化，应该怎么调整 C？

- A. 减小 C，例如从 1 改为 0.1
- B. 增大 C，例如从 1 改为 10
- C. 把 `max_iter` 改成 10000

**2.** C 从 10 降到 0.01，权重明显变小，但预测标签和准确率都没变化，这说明什么？

- A. 模型参数变化了，但还没有改变分类边界对这些样本的判断结果
- B. 正则化没有生效
- C. C 参数不能影响模型权重

**3.** C 不断减小，权重越来越小，预测概率越来越接近 0.5，这说明什么？

- A. 正则化增强，模型受到更强约束，可能逐渐欠拟合
- B. 模型越来越聪明，准确率一定越来越高
- C. 正则化没有发挥作用

**4.** 如果 L1 正则化让 100 个特征中的 70 个权重变成了 0，这意味着什么？

- A. 模型自动把一部分特征的影响去掉了
- B. 模型删除了 70 条训练数据
- C. 模型准确率一定提高 70%

<details>
<summary>答案</summary>

1. A。C 和正则化强度是反过来的。
2. A。权重从 6.92 降到 0.0166 就是生效的证据，只是概率没跨过 0.5。
3. A。方向是对的。不过在这组数据上，L2 压到很小训练集也一直是 100%，没有真的欠拟合；真正的欠拟合看第七部分 L1 的结果。
4. A。变的是特征的权重，不是训练数据。

</details>
