# 第 27 课：监督学习与文本分类

上一课你说太简单了，那从这一课开始提高实战强度。今天不只学概念，要亲手搭一个小型商品评论数据集，把它变成特征，再分成训练集和测试集，为下一课训练第一个分类模型做准备。

## 一、什么是监督学习？

我们有一些商品评论，而且已经知道每条是好评还是差评：

| 评论 | 正确答案 |
|---|---|
| 这个手机非常好用 | 好评 |
| 电池续航特别差 | 差评 |
| 拍照效果很棒 | 好评 |
| 质量太差了 | 差评 |

把这些**带着正确答案**的数据交给模型，让它学其中的规律，这就叫**监督学习（Supervised Learning）**。

它有两个组成部分：

- 输入 $X$：评论处理后得到的文本特征
- 标签 $y$：评论对应的正确类别

模型要学的就是从 $X$ 到 $y$ 的对应关系：

$$
X \longrightarrow y
$$

注意，模型不是简单地记住每条评论，而是希望学到能用在**新评论**上的规律。

## 二、监督学习和无监督学习有什么区别？

| 类型 | 有没有正确答案 | 例子 |
|---|---|---|
| 监督学习 | 有 | 判断评论是好评还是差评 |
| 无监督学习 | 没有 | 自动把相似的评论分成几群 |

NLP 里常见的任务：

- 文本分类：判断新闻类别、情感倾向
- 文本匹配：判断两句话意思是否相近
- 命名实体识别：找出人名、地名、机构名
- 文本聚类：自动发现相似的文本群（这个是无监督的）

## 三、第一个实战：构建训练数据

```python
# 商品评论数据集
texts = [
    "这个手机非常好用",
    "电池续航特别好",
    "拍照效果好",
    "手机质量很好",
    "这个手机太差了",
    "电池续航很差",
    "拍照效果不好",
    "手机质量太差"
]

# 1 代表好评，0 代表差评
labels = [1, 1, 1, 1, 0, 0, 0, 0]

print(len(texts))
print(len(labels))
```

```text
8
8
```

- `texts`：8 条评论，也就是输入数据 $X$ 的来源
- `labels`：8 个标签，也就是正确答案 $y$

为什么两个列表长度必须一样？因为每条评论都要有一个对应的答案。`texts[0]` 是「这个手机非常好用」，`labels[0]` 是 1，意思是第一条评论是好评。

## 四、把文本转换为特征

把 TF-IDF 真正用起来：

```python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(texts)

print("特征矩阵形状：", X.shape)
print("词汇表：", vectorizer.get_feature_names_out())
```

```text
特征矩阵形状： (8, 8)
词汇表： ['手机质量太差' '手机质量很好' '拍照效果不好' '拍照效果好' '电池续航很差' '电池续航特别好' '这个手机太差了'
 '这个手机非常好用']
```

8 行没问题，8 条评论。可是只有 8 列，而且看看词汇表：**每一整句话都被当成了一个「词」。**

原因是 `TfidfVectorizer` 默认的切词规则是给英文设计的，靠空格和标点来切。中文词与词之间没有空格，它找不到切点，一整串汉字就成了一个词。

这样的特征根本没法学：模型看到的不是「好用 → 好评」，而是「这个手机非常好用 → 好评」。换一句「这个相机非常好用」，词表里查不到，特征全是 0。

### 解决：用 jieba 做中文分词

先安装：

```bash
pip install jieba
```

然后把分词函数交给 `TfidfVectorizer`：

```python
import jieba
from sklearn.feature_extraction.text import TfidfVectorizer

# 中文分词
def chinese_tokenizer(text):
    return jieba.lcut(text)

vectorizer = TfidfVectorizer(
    tokenizer=chinese_tokenizer,
    token_pattern=None
)

X = vectorizer.fit_transform(texts)

print(jieba.lcut("这个手机非常好用"))
print("特征矩阵形状：", X.shape)
print("词汇表：", vectorizer.get_feature_names_out())
```

```text
['这个', '手机', '非常', '好用']
特征矩阵形状： (8, 18)
词汇表： ['不好' '了' '太' '太差' '好' '好用' '差' '很' '很差' '手机' '拍照' '效果' '特别' '电池' '续航'
 '质量' '这个' '非常']
```

从 8 个特征变成 18 个，「手机」「好用」「太差」终于成了独立的词，可以在不同评论之间共用了。

两个参数要一起写：

| 参数 | 作用 |
|---|---|
| `tokenizer=chinese_tokenizer` | 用自己的函数替换默认的切词方式 |
| `token_pattern=None` | 关掉默认的切词规则，否则 sklearn 会提示这个参数被忽略 |

`jieba.lcut()` 返回一个列表（`l` 就是 list）。具体怎么切，受 jieba 的词典和版本影响。

## 五、训练集和测试集：真正开始机器学习

用 scikit-learn 的 `train_test_split()`：

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X,
    labels,
    test_size=0.25,
    random_state=42,
    stratify=labels
)

print("全部数据：", X.shape)
print("训练集：", X_train.shape)
print("测试集：", X_test.shape)
print("训练标签：", y_train)
print("测试标签：", y_test)
```

```text
全部数据： (8, 18)
训练集： (6, 18)
测试集： (2, 18)
训练标签： [1, 0, 1, 1, 0, 0]
测试标签： [0, 1]
```

返回值的顺序是固定的：`X_train, X_test, y_train, y_test`，先 X 的两份，再 y 的两份。

| 参数 | 作用 |
|---|---|
| `X` | 文本特征 |
| `labels` | 正确标签 |
| `test_size=0.25` | 25% 的数据作为测试集，8 条里拿 2 条 |
| `random_state=42` | 固定随机划分的结果，方便复现 |
| `stratify=labels` | 让训练集和测试集里好评、差评的比例尽量一致 |

### 为什么 X 大写、y 小写？

这是数学记号的习惯，Python 并不要求：

- 大写 `X` 表示一个**矩阵**：每一行是一条评论，每一列是一个特征
- 小写 `y` 表示一个**向量**：每条评论一个标签

整个 sklearn 都这么写，`fit(X, y)`、`predict(X)`，跟着写，别人一眼就知道哪个是输入、哪个是答案。

### `random_state` 是什么？

划分是随机的。不固定的话，这次测试集是第 2、7 条，下次可能就变成第 5、8 条，准确率也跟着变。你改了一个参数，准确率变了，到底是参数的功劳，还是划分的运气？分不清。

`random_state=42` 把随机过程固定住，同样的数据和参数，每次都得到同样的划分。42 没有任何特殊含义，写 0、10、100 都行，只是教程里习惯用它。

### `stratify` 是什么？

8 条里好评 4 条、差评 4 条。不分层的话，随机抽 2 条当测试集，可能两条都是好评，模型全猜好评就能拿 100%，这个分数毫无意义。

`stratify=labels` 按标签比例抽样。上面的测试集 `[0, 1]` 正好一条差评一条好评。**样本越少，这个参数越要紧。**

> 注意：上面先对全部 8 条 `fit_transform` 再划分，测试集的词也进了词表，这叫**数据泄漏**。规范写法是先划分原始文本，只用训练集 `fit`，测试集只 `transform`。下一课开始都用规范写法。
<details>
<summary>实测细节</summary>

两种写法我都跑了：泄漏写法词表 18 个词，规范写法只有 15 个，多出来的 `不好`、`拍照`、`效果` 正好是测试集那两条评论独有的词。

规范写法下，测试集的「拍照效果不好」三个词一个都不在词表里，变成了**全零向量**。逻辑回归照样「猜对」了这条，但靠的只是截距：差评概率 0.5086，好评 0.4914，和抛硬币差不多。泄漏会让测试结果看起来比真实情况好。
