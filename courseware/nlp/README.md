## 怎么学

- **一课一个文件**，放在对应阶段的文件夹里，文件名前面是编号，按文件名排序就是学习顺序。
- **只看源文件也能学**：在 Kiro / VS Code 里打开一个 `.md`，按 `Ctrl+Shift+V` 看排版后的预览，公式、表格、折叠的小测答案都能正常显示，指向代码的链接点了直接打开文件。
- **每课的顺序**：讲概念 → 演示（代码和真实输出）→ 今天的作业 → 小测。
- **作业写在** 仓库根目录的 `nlp/courseNN/`（和原来一样）。写完把运行输出发给我（或者说一声「第 34 课 做完了」），讲评会追加到那一课的文件末尾。
- 想要进度条、打勾和全文搜索，就打开网站：在 `courseware/` 下运行 `npm run docs:dev`。
