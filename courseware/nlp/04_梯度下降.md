# 第一部分 · 知识讲解

## 1. 梯度下降：把方向和步长合起来

第 03 节算出了梯度：

$$
g = \frac{dL}{dw} = 2x(wx - y)
$$

梯度给了两个信息：

| 信息 | 来自 |
|---|---|
| **往哪边走** | 符号（正还是负） |
| **坡有多陡** | 绝对值大小 |

但梯度本身不是「该调多少」——它只是变化率。真正的更新公式是：

$$
\boxed{w_{\text{新}} = w_{\text{旧}} - \eta \cdot g}
$$

| 符号 | 含义 |
|---|---|
| $w$ | 参数 |
| $\eta$（读 eta） | **学习率**，决定步子大小 |
| $g$ | 梯度 |

## 2. 那个减号从哪来

这是最容易记混的地方。**为什么是减去梯度，而不是加上？**

因为**梯度指向损失上升最快的方向**。想让损失下降，就要往反方向走。

用具体数字看（`x=2`、`y=6`，理想 `w=3`）：

| 当前 `w` | 梯度 $g=2x(wx-y)$ | 符号 | 该怎么调 | 公式做了什么 |
|---|---|---|---|---|
| 1（在最低点左边） | $2\cdot2\cdot(2-6)=-16$ | 负 | **增大** `w` | $1 - \eta(-16) = 1 + 1.6$ ✅ 增大了 |
| 5（在最低点右边） | $2\cdot2\cdot(10-6)=16$ | 正 | **减小** `w` | $5 - \eta(16) = 5 - 1.6$ ✅ 减小了 |
| 3（在最低点） | $2\cdot2\cdot(6-6)=0$ | 零 | **不动** | $3 - \eta \cdot 0 = 3$ ✅ 不动 |

**减号自动处理了方向**：梯度为负就加、为正就减，不用写 `if`。

这也解释了第 03 节那张损失曲线的几何意义——减号让参数总是朝着下坡方向移动。

> 「梯度**下降**」这个名字就是这么来的：沿梯度的**反**方向走，让损失**下降**。

## 3. 学习率：步子有多大

梯度告诉你方向和坡度，但走多远由学习率决定。

$$
\text{这一步移动的距离} = \eta \times |g|
$$

同一个位置（`w=1`，梯度 `-16`），不同学习率的第一步：

| 学习率 | 计算 | 新的 `w` | 新损失 | 结果 |
|---|---|---|---|---|
| 0.1 | $1 - 0.1\times(-16)$ | **2.6** | 0.64 | 从 16 降到 0.64，很好 |
| 0.3 | $1 - 0.3\times(-16)$ | **5.8** | 31.36 | **从 16 升到 31.36，反而变差** |

`lr=0.3` 的问题是：目标在 `w=3`，结果一步跨到了 5.8，**冲过头了**。

## 4. 实测：四种学习率的命运

把 `day_4.py` 的循环跑 10 轮，只改学习率：

### `lr = 0.1`（合适）

```text
  轮       预测 ŷ         损失 L       梯度 g      更新后 w
  1     2.0000      16.0000   -16.0000     2.6000
  2     5.2000       0.6400    -3.2000     2.9200
  3     5.8400       0.0256    -0.6400     2.9840
  4     5.9680       0.0010    -0.1280     2.9968
  5     5.9936       0.0000    -0.0256     2.9994
  ...
  9     6.0000       0.0000    -0.0000     3.0000
```

**9 轮就收敛到 3.0000。** 注意观察三个数同时在变小：损失 16 → 0，梯度 -16 → 0，而 `w` 稳稳走向 3。

**梯度自己会变小**——越接近最低点坡越平，所以步子自动变短。这是梯度下降的优雅之处：不需要手动减速。

### `lr = 0.01`（太小）

```text
  1     2.0000      16.0000   -16.0000     1.1600
  2     2.3200      13.5424   -14.7200     1.3072
  ...
 10     4.1114       3.5670    -7.5546     2.1312
```

**10 轮只走到 2.13，损失还有 3.57。** 方向完全正确，就是太慢——要几十轮才能到 3。

真实训练里这意味着：GPU 跑一天，模型还没学明白。

### `lr = 0.3`（太大）

```text
  1     2.0000      16.0000   -16.0000     5.8000
  2    11.6000      31.3600    22.4000    -0.9200
  3    -1.8400      61.4656   -31.3600     8.4880
  4    16.9760     120.4726    43.9040    -4.6832
  5    -9.3664     236.1262   -61.4656    13.7565
  ...
  8    48.1654    1777.9211   168.6616   -26.5158
```

**这不是「慢」，是彻底坏了。** `w` 在 5.8 → -0.92 → 8.49 → -4.68 之间来回跳，而且**幅度越来越大**，损失从 16 涨到 1777。

每一步都在正确的方向上，但步子太大，每次都冲到对面更远的地方——像在山谷两侧来回弹，越弹越高。

### `lr = 0.6`（灾难）

```text
  8 45772.2330 2094548086.3787 183064.9321 -86952.8428
```

8 轮后 `w = -86952`，损失 **20 亿**。再跑几轮就会溢出成 `inf`，然后变成 `nan`。

> **真实训练里出现 `nan` loss，第一个要怀疑的就是学习率太大。** 这是最常见的原因。

## 5. 收敛的临界条件

上面四个结果有个精确的分界线，可以算出来。

对 $L=(2w-6)^2$，梯度是 $g=8(w-3)$。代入更新公式：

$$
w' = w - \eta \cdot 8(w-3)
$$

两边同时减 3（看「离目标还有多远」）：

$$
w' - 3 = (w - 3) - 8\eta(w-3) = (1 - 8\eta)(w - 3)
$$

**每走一步，离目标的距离就乘上一个因子 $(1-8\eta)$。** 所以：

| 条件 | 结果 |
|---|---|
| $\lvert 1-8\eta \rvert < 1$ | 距离不断缩小 → **收敛** |
| $\lvert 1-8\eta \rvert = 1$ | 距离不变 → **原地震荡** |
| $\lvert 1-8\eta \rvert > 1$ | 距离不断放大 → **发散** |

解出收敛范围：

$$
0 < \eta < 0.25
$$

实测验证：

```text
  lr=0.1   |1-8·lr| = 0.20  → 收敛
  lr=0.2   |1-8·lr| = 0.60  → 收敛
  lr=0.25  |1-8·lr| = 1.00  → 震荡不前
  lr=0.3   |1-8·lr| = 1.40  → 发散
  lr=0.5   |1-8·lr| = 3.00  → 发散
```

**所以 `lr=0.3` 不是「可能震荡」，而是必然发散**——它已经越过了 0.25 这条线。

> 这个临界值 **0.25 = 1/4** 不是巧合。更一般地，对 $L=(wx-y)^2$ 这类二次损失，
> 临界学习率是 $\dfrac{1}{x^2}$（这里 $x=2$，所以是 $1/4$）。
>
> 两个推论：
> 1. **输入特征的大小会影响合适的学习率。** `x` 变大，临界学习率急剧变小。这正是实际项目里
>    要做**特征归一化**的原因之一——让所有特征的尺度接近，才能用同一个学习率。
> 2. 真实模型的损失不是简单二次函数，没有这么干净的公式。所以学习率只能靠**试**
>    （常见做法：从 0.1、0.01、0.001 里试，看损失曲线）。

## 6. 为什么要训练很多轮

一次更新从 `w=1` 到 `w=2.6`，预测从 2 变成 5.2——接近 6 了，但没到。

原因是**梯度只描述当前位置的局部信息**。走一步之后位置变了，新位置的坡度也变了，得重新算。

所以训练是个反复过程：

```text
算梯度 → 走一步 → 重新算梯度 → 再走一步 → ...
```

这解释了第 15 课那道题：**为什么每轮都要重新计算梯度？** 因为参数更新后，预测变了、误差变了、梯度也就变了。**不能一直用旧梯度**。

从实测数据能直接看到梯度在变：`-16 → -3.2 → -0.64 → -0.128 → ...`

## 7. 训练循环的五个步骤

```python
for step in range(10):
    y_pred = w * x                      # 1. 预测
    loss = (y_pred - y) ** 2            # 2. 算损失
    gradient = 2 * x * (w * x - y)      # 3. 算梯度
    w = w - lr * gradient               # 4. 更新参数
    print(...)                          # 5. 观察
```

| 步 | 做什么 | 对应的公式 |
|---|---|---|
| 1 | 前向计算，得到预测 | $\hat y = wx$ |
| 2 | 衡量差距 | $L=(\hat y-y)^2$ |
| 3 | 算变化率 | $g=2x(wx-y)$ |
| 4 | 沿反方向走一步 | $w \leftarrow w - \eta g$ |
| 5 | 打印日志，确认损失在降 | —— |

**这五步就是所有深度学习训练的骨架。** PyTorch 里的写法是：

```python
y_pred = model(x)                # 1. 预测（前向传播）
loss = criterion(y_pred, y)      # 2. 算损失
loss.backward()                  # 3. 算梯度（反向传播，自动求导）
optimizer.step()                 # 4. 更新参数
optimizer.zero_grad()            # （清空梯度，准备下一轮）
```

**一一对应。** 区别只是第 3 步不用手推公式了（框架自动求导），第 4 步有更聪明的优化器（Adam 等）。
**手写过这五步，再看 PyTorch 就不是黑盒。**

# 第二部分 · 当时的练习与代码

## `Day3.py`：单步梯度下降

最早的那份代码只走一步：

```python
x = 2.0            # 参数值
y = 4.0            # 预期值
w = 1.0            # 权重
learning_rate = 0.1

prediction = x * w                      # 预测值
loss = (prediction - y) ** 2            # 损失
gradient = 2 * x * (prediction - y)     # 损失对权重的导数

w = w - learning_rate * gradient
print("更新后的权重:", w)
```

代入算一遍：预测 $1\times2=2$，损失 $(2-4)^2=4$，梯度 $2\times2\times(2-4)=-8$，
更新后 $w = 1-0.1\times(-8) = 1.8$。

理想权重是 $y/x = 2$，走一步从 1 到 1.8，方向正确。

**这份代码的价值是把第 02、03 节的三个公式串成了可执行的流程。** 但它只走一步，看不到「学习」的过程。

## `day_4.py`：10 轮循环

第 15 课的作业，加了 `for` 循环：

```python
y = 6              # 目标值
lr = 0.1           # 学习率
x = 2              # 输入
w = 1.0            # 权重

for i in range(10):
    y_pred = w * x
    loss = (y_pred - y) ** 2
    gradient = 2 * x * (w * x - y)
    w = w - lr * gradient
    print(f"------------------第{i+1}次------------------------")
    print("预测值:", y_pred)
    print("损失:", loss)
    print("梯度:", gradient)
    print("更新后的w:", w)
```

**这是 B 线第一份完整的机器学习程序**，当时给了满分。它做对了五件事：数据设置、权重初始化、循环、每轮重算预测和梯度、更新并打印。

实际运行结果（前 5 轮）：

| 轮 | 预测 | 损失 | 梯度 | 更新后 w |
|---:|---:|---:|---:|---:|
| 1 | 2.0000 | 16.0000 | -16.0000 | 2.6000 |
| 2 | 5.2000 | 0.6400 | -3.2000 | 2.9200 |
| 3 | 5.8400 | 0.0256 | -0.6400 | 2.9840 |
| 4 | 5.9680 | 0.0010 | -0.1280 | 2.9968 |
| 5 | 5.9936 | 0.0000 | -0.0256 | 2.9994 |

**损失从 16 降到接近 0，权重从 1 走到 3。** 为什么是 3？因为要让 $2w=6$，所以 $w=3$。

> 这张表最值得看的是**收敛速度**：第 1 轮损失降了 96%（16 → 0.64），之后每轮都在接近。
> 这种「先快后慢」的形状是梯度下降的典型特征——离得远时坡陡走得快，接近目标时坡平自动减速。

## 两个被指出的代码细节

**一、注释写错了含义。**

```python
# 预测值
y = 6
```

`y = 6` 是**目标值（正确答案）**，不是预测值。预测值是循环里算出来的 `y_pred`。

这个注释错误值得记——**它说明当时对「预测值」和「真实值」两个概念还没完全分开**。而这两者的区别正是损失函数存在的理由（第 02 节）。注释写错往往暴露理解上的模糊。

**二、打印的是更新前的预测值。**

代码顺序是先算 `y_pred` 和 `loss`，再更新 `w`。所以每轮打印的「预测值」和「损失」属于**更新前**的模型状态，而「更新后的 w」是更新后的值。

这不是错误（也是常见的训练日志写法），但要知道这个错位。看实测表格第 1 行：预测 2.0、损失 16.0 对应的是 `w=1.0`，而那一行显示的 `w` 已经是 2.6 了。
