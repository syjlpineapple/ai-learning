# 预备课 1：NumPy 数组

这是 NLP 学习计划的第 1 天。你的目标是算法、训练和微调模型，所以今天先不急着装一堆深度学习框架，从 NumPy 开始。

为什么是 NumPy？计算机不能直接处理文字，一段文字要先变成**一串数字**（向量），很多条文字摆在一起就成了一张数字表（矩阵）。后面的模型打分、相似度计算，底层都是在算这些数字。NumPy 就是 Python 里做这类计算的标准工具。

今天花一小时：前 15 分钟学数组、`shape`、均值和点积，接下来 35 分钟自己运行代码、改数字做实验，最后 10 分钟写下你的理解。

## 一、先运行这段代码

```python
import numpy as np

# 三条评论对应的简单特征
X = np.array([
    [1, 0, 2],
    [0, 1, 1],
    [2, 1, 0]
])

# 每一列的平均值
print("平均值:", X.mean(axis=0))

# 一个特征向量与权重向量的点积
x = np.array([1, 2, 3])
w = np.array([0.2, 0.5, -0.1])

score = np.dot(x, w)
print("得分:", score)
print("矩阵形状:", X.shape)
```

```text
平均值: [1.         0.66666667 1.        ]
得分: 0.8999999999999999
矩阵形状: (3, 3)
```

下面一行一行看它们是什么意思。

## 二、`shape`：数组的形状

`np.array()` 造出来的东西叫 NumPy 数组（`ndarray`）。`X` 有 3 行、3 列，所以：

```python
X.shape
# (3, 3)
```

`shape` 返回的是每个维度的大小。二维数组按 `(行数, 列数)` 来写，行在前。

可以把 `X` 理解成 3 个样本（3 条评论），每个样本有 3 个特征。后面学 NLP 时，你会经常用 `shape` 检查「有几条文本、每条有几个特征」对不对得上。

## 三、`axis=0`：沿哪个方向求平均

先记住一句话：**对二维数组，`axis=0` 是把每一列汇总起来，`axis=1` 是把每一行汇总起来。**

上面那个 3×3 的矩阵不适合用来讲这个，因为它恰好是对称的，按行算和按列算结果一模一样，看不出区别。我们换一个 2 行 3 列的：

```python
X = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(X.mean(axis=0))
print(X.mean(axis=1))
```

```text
[2.5 3.5 4.5]
[2. 5.]
```

`axis=0`，每一列算一个平均值：

| 列 | 计算 | 结果 |
|---|---|---:|
| 第 1 列 | $(1+4)/2$ | 2.5 |
| 第 2 列 | $(2+5)/2$ | 3.5 |
| 第 3 列 | $(3+6)/2$ | 4.5 |

`axis=1`，每一行算一个平均值：

| 行 | 计算 | 结果 |
|---|---|---:|
| 第 1 行 | $(1+2+3)/3$ | 2 |
| 第 2 行 | $(4+5+6)/3$ | 5 |

最好用的判断方法是**数结果有几个**：形状 `(2, 3)` 的矩阵，`axis=0` 得到 3 个数（等于列数），`axis=1` 得到 2 个数（等于行数）。不写 `axis`，`X.mean()` 就是所有数字一起平均，只得到一个数。

试一试：

```python
X = np.array([
    [2, 4, 6],
    [4, 6, 8]
])
```

执行 `X.mean(axis=0)`，结果是什么？

- A. `[3, 5, 7]`
- B. `[4, 6, 8]`
- C. `5`

<details>
<summary>答案</summary>

A。每一列平均：$(2+4)/2=3$，$(4+6)/2=5$，$(6+8)/2=7$。实际打印出来是 `[3. 5. 7.]`。

</details>

## 四、点积：对应位置相乘，再加起来

```python
x = np.array([1, 2, 3])
w = np.array([0.2, 0.5, -0.1])
```

$$
\begin{aligned}
x\cdot w &= 1\times0.2+2\times0.5+3\times(-0.1)\\
&= 0.2+1.0-0.3\\
&= 0.9
\end{aligned}
$$

两个要点：两个向量长度必须一样，才能一一对应；结果是**一个数**，不是一串数。

点积不是把两个向量相加，也不是把所有数字乘在一起。用 `a=[2, 3]`、`b=[4, 5]` 对比一下：

| 写法 | 结果 | 做了什么 |
|---|---|---|
| `a + b` | `[6 8]` | 对应位置相加 |
| `a * b` | `[ 8 15]` | 对应位置相乘 |
| `np.dot(a, b)` | `23` | 对应位置相乘，再求和 |

为什么 NLP 要用点积？一条文本变成特征向量 `x` 以后，模型给每个特征一个权重 `w`，表示这个特征有多重要。`x` 和 `w` 做点积，就得到这条文本的分数。逻辑回归、神经网络的每一层，算的都是这个。

> 注意：程序实际打印的是 `0.8999999999999999`，不是 `0.9`。0.2、0.5、0.1 这些小数在计算机里是用二进制近似存的，算完会差一点点。这不是你算错了，后面看到这种结果，知道它就是 0.9 即可。

## 五、两个顺手问到的问题

**为什么打印出来没有逗号？** NumPy 数组打印时用空格分隔，Python 列表用逗号分隔：

```python
print(np.array([1, 2, 3]))   # [1 2 3]
print([1, 2, 3])             # [1, 2, 3]
```

这是 NumPy 为了让大矩阵排得整齐。`[1.         0.66666667 1.        ]` 里那些空格是为了让小数点对齐。想要逗号，可以 `X.mean(axis=0).tolist()`，得到 `[1.0, 0.6666666666666666, 1.0]`。

**为什么用大写的 `X`？** 语法上大小写都行，这是机器学习的习惯：

| 变量 | 通常代表 |
|---|---|
| `X` | 一批样本组成的特征矩阵 |
| `x` | 一个样本的特征向量，比如 `X[0]` 就是 `[1 0 2]` |
| `w` | 权重 |
| `y` | 要预测的目标（标签） |
| `b` | 偏置 |

记住：大写是一批，小写是一个。
