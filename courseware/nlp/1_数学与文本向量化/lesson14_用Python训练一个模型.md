# 第 14 课：用 Python 亲手训练一个模型

上一课三道题全对：两层变化率 3 和 4 要相乘得 12；预测多 1、答案不变，误差就多 1；参数通过预测和误差间接影响损失，所以要用链式法则。

选择题还不能完全证明你能独立计算，所以今天不加新的数学，而是把学过的**预测、损失、梯度、学习率和梯度下降**连起来，用代码跑一遍。

## 一、先回顾训练流程

| 步骤 | 做什么 | 公式 |
|---|---|---|
| ① | 输入数据 | $x=2,\ y=6$ |
| ② | 模型做预测 | $\hat y=wx$ |
| ③ | 计算损失和梯度 | $L=(\hat y-y)^2$，$\text{gradient}=2x(wx-y)$ |
| ④ | 更新参数 $w$ | $w_{\text{new}}=w_{\text{old}}-\eta\cdot\text{gradient}$ |

重复这几步，通常就能让损失逐渐变小。$\eta$ 就是学习率，控制每次更新走多大一步。

## 二、用 Python 执行一次训练

从熟悉的例子开始：输入 $x=2$，正确答案 $y=6$，初始参数 $w=1$，学习率 `lr = 0.1`。

```python
x = 2
y = 6
w = 1.0
lr = 0.1

# 1. 模型预测
y_pred = w * x

# 2. 计算损失
loss = (y_pred - y) ** 2

# 3. 计算梯度
gradient = 2 * x * (w * x - y)

# 4. 更新参数
w = w - lr * gradient

print("预测值：", y_pred)
print("损失：", loss)
print("梯度：", gradient)
print("更新后的 w：", w)
```

```text
预测值： 2.0
损失： 16.0
梯度： -16.0
更新后的 w： 2.6
```

打印出来带 `.0`，是因为 `w = 1.0` 是小数，和它一起算出来的结果也都是小数。

对照每一行的含义：

| 项目 | 结果 | 含义 |
|---|---:|---|
| 预测值 | 2 | 模型预测 2，正确答案是 6 |
| 损失 | 16 | 预测与正确答案差距较大 |
| 梯度 | -16 | 参数 $w$ 应该往增大的方向调 |
| 更新后的 $w$ | 2.6 | 参数从 1 增加到了 2.6 |

**注意这个关键点：**

$$
w_{\text{new}}=1-0.1\times(-16)=2.6
$$

梯度是负数，所以「减去负数」就变成了加法。

代码里每一行都对应一个你学过的公式：`**` 是 Python 的乘方，`** 2` 就是平方；`gradient` 那一行就是上一课用链式法则推出来的 $2x(wx-y)$。

## 三、更新一次后，模型变好了吗？

用新参数 $w=2.6$ 再预测：

$$
\hat y=2.6\times2=5.2
$$

新的损失：

$$
L=(5.2-6)^2=0.64
$$

损失从 **16 降到了 0.64**。在这个例子里，模型更新一次就明显接近正确答案了。

这就是训练的核心：**预测 → 计算误差 → 计算梯度 → 更新参数 → 再预测。**

## 五、练习

**第 1 题：** 代码中的 `w = w - lr * gradient`，如果 `gradient = -10`、`lr = 0.1`、原来的 `w = 2`，更新后是多少？

- A. 1
- B. 2
- C. 3

**第 2 题：** 如果损失从 16 降到 0.64，通常说明什么？

- A. 这次更新让预测更接近正确答案了
- B. 模型的参数必须变成 0
- C. 模型以后永远不会预测错误

**第 3 题：** 代码中的 `** 2` 表示什么？

- A. 乘以 2
- B. 平方，也就是乘以自己
- C. 把数字除以 2

<details>
<summary>答案</summary>

1. C。$2-0.1\times(-10)=2+1=3$。梯度为负，参数增大。
2. A。不过损失降了一次，不代表之后每次更新都一定会降。
3. B。`3 ** 2` 的结果是 `9`。

</details>

## 讲评（10-22）

你选了 C、A、B，三题全对。梯度下降更新参数的计算、Python 里平方的写法，你都掌握了。

这节课的单步更新，你在 `nlp/Day3.py` 里其实已经写过一次。那份代码照的是 10-20 第 3 天练习的例子，把正确答案设成 4：

```python
# 参数值
x = 2.0

# 预期值
y = 4.0

# 权重
w = 1.0

# 学习率
learning_rate = 0.1

# 预测值
prediction = x * w

# 损失
loss = (prediction - y) ** 2

# 损失对权重的导数
gradient = 2 * x * (prediction - y)

w = w - learning_rate * gradient

print("更新后的权重:", w)
```

```text
更新后的权重: 1.8
```

算一遍：预测 $2\times1=2$，梯度 $2\times2\times(2-4)=-8$，更新后 $1-0.1\times(-8)=1.8$。理想权重是 $4\div2=2$，走一步从 1 到 1.8，方向对了。当时 GPT 在第 3 天的课文里先写了「运行结果 2.2」，随后自己改成了 1.8，实际运行就是 1.8。

`gradient` 那一行你写的是 `prediction - y`，今天课文写的是 `w * x - y`，两者是同一个数，因为 `prediction` 就是 `w * x`。

一个小地方：`x` 上面的注释写的是「参数值」。按第 4 课的说法，`x` 是**输入数据**，**参数**是模型要学的 `w`。注释写成「输入」会更准确。这两个词分清了，读别人的代码时才不会搞混谁该被训练。
