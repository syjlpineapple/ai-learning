# 第 19 课：文本向量表示入门

上一课你学会了算两个向量有多像。可是前面的向量都是我编的，一句真实的话，怎么变成一个向量？今天学最简单的一种办法：**词袋模型**。它是后面 TF-IDF、文本分类的基础。

## 一、为什么要把文本变成数字？

假设有两句话：

- 句子 A：我喜欢猫
- 句子 B：我喜欢狗

人能直接读懂，但计算机做数学计算需要数字。

第 16 课学过词 ID，比如：

| Token | ID |
|---|---:|
| 我 | 0 |
| 喜欢 | 1 |
| 猫 | 2 |
| 狗 | 3 |

「我喜欢猫」可以写成 `[0, 1, 2]`。

但这只是把每个词换成编号。**词 ID 不代表词的含义，也表示不了一个词出现了几次。** 「猫猫猫」是 `[2, 2, 2]`，和 `[0, 1, 2]` 放在一起，没法直接比。

所以今天换一种表示方法。

## 二、认识词袋模型（Bag of Words）

词袋模型的想法很简单：

**先固定一个词表，统计文本里每个词出现了几次，再把这些次数排成一个向量。**

词表固定为 `[我, 喜欢, 猫, 狗]`。

「我喜欢猫」的统计结果：

- 「我」出现 1 次
- 「喜欢」出现 1 次
- 「猫」出现 1 次
- 「狗」出现 0 次

所以它的向量是：

$$
[1,1,1,0]
$$

「我喜欢狗」的向量则是：

$$
[1,1,0,1]
$$

放在一张表里看：

| 句子 | 我 | 喜欢 | 猫 | 狗 | 向量 |
|---|---:|---:|---:|---:|---|
| A：我喜欢猫 | 1 | 1 | 1 | 0 | `[1, 1, 1, 0]` |
| B：我喜欢狗 | 1 | 1 | 0 | 1 | `[1, 1, 0, 1]` |

注意两点：

- 两个向量的长度都是 4，因为词表里有 4 个词。**向量长度由词表决定，和句子长短无关。**
- 每个位置的意思是固定的：第 0 位永远是「我」出现了几次，第 3 位永远是「狗」出现了几次。

这样，两句话就落在了同一套坐标里，可以直接拿上一课的余弦相似度去比了。

### 词袋模型有什么特点？

- **优点**：简单、好理解，计算机处理起来方便。
- **局限**：不考虑词语的先后顺序，也不真正理解词语的意思。

比如「猫喜欢我」和「我喜欢猫」，统计出来都是 `[1, 1, 1, 0]`，一模一样，可意思完全不同。这就是「袋子」这个名字的由来：把词扔进袋子里摇一摇，顺序就没了。

## 三、用 Python 动手实现

不用任何库，自己写出统计过程：

```python
vocab = ["我", "喜欢", "猫", "狗"]

text = ["我", "喜欢", "猫"]

vector = []

for word in vocab:
    count = text.count(word)
    vector.append(count)

print(vector)
```

输出：

```text
[1, 1, 1, 0]
```

逐行看：

1. `vocab`：规定词表，也规定了向量每一位的顺序。
2. `text`：要处理的文本，这里假设已经分好词了。
3. `for word in vocab`：按词表顺序，依次检查每个词。
4. `text.count(word)`：数一数这个词在文本里出现了几次。
5. `vector.append(count)`：把次数放进向量。

如果文本是 `["我", "喜欢", "猫", "猫"]`，结果就是 `[1, 1, 2, 0]`，因为「猫」出现了两次。

这是帮你理解原理的教学代码。真实的中文文本还需要先分词。

## 四、小测

直接回复三道题的答案就行，比如 `1A，2B，3C`。

**1.** 词袋模型主要做什么？

- A. 统计词语出现的次数，并形成向量
- B. 自动理解句子的全部语义
- C. 给每句话随机分配一个数字

**2.** 词表是 `[我, 喜欢, 猫, 狗]`，文本是「我喜欢猫」，正确的词袋向量是什么？

- A. `[0, 1, 2]`
- B. `[1, 1, 1, 0]`
- C. `[1, 1, 1]`

**3.** 词袋模型的一个主要局限是什么？

- A. 它无法把文本表示成数字
- B. 它要求每个词只能出现一次
- C. 它通常不保留词语的先后顺序

<details>
<summary>答案</summary>

1. A。核心就是「数次数」。
2. B。A 是词 ID 序列，不是词袋向量；C 少了「狗」那一位，词表有 4 个词，向量就必须是 4 位。
3. C。「我喜欢猫」和「猫喜欢我」会得到同一个向量。

</details>

今天最重要的不是记住英文术语，而是理解：**文本可以按照固定的词表，变成有规律的数字向量。**

## 讲评（10-23）

你交的是 **A、B、C**，三题全对。

`day_6.py` 里你写的词表是 `["我", "喜欢", "狗", "猫"]`，把狗放在了猫前面，跑出来是：

```text
[1, 1, 0, 1]
```

这个结果是对的，而且正好说明了一件事：同一句「我喜欢猫」，换一个词表顺序，向量就变了。所以**用词袋比较两句话时，必须用同一个词表**，否则第 2 位在一句里是「猫」、在另一句里是「狗」，比出来毫无意义。
