# 预备课 2：矩阵乘法

昨天你学会了点积：一个特征向量和一个权重向量，算出一个分数。今天弄懂一个核心问题：**模型怎样把一批句子变成数字，一次算出所有分数？**

## 一、一个模型怎样给句子打分

假设我们想判断电影评论是正面还是负面。为了先看懂计算，把每条评论简化成两个特征：正面词的数量、负面词的数量。

| 评论 | 正面词数量 | 负面词数量 |
|---|---:|---:|
| 电影太棒了 | 3 | 0 |
| 电影很无聊 | 0 | 2 |
| 剧情不错，但很无聊 | 2 | 1 |

把它们放进矩阵 `X`：

```python
import numpy as np

X = np.array([
    [3, 0],
    [0, 2],
    [2, 1]
])
```

`X.shape` 是 `(3, 2)`：3 条评论，每条 2 个特征。

## 二、权重是什么

模型会学习每个特征有多重要。今天先手动设一个：

```python
w = np.array([2, -1])
```

正面词权重是 2，正面词越多分数越高；负面词权重是 -1，负面词越多分数越低。

用昨天学的点积，一条一条算：

| 评论 | 计算 | 分数 |
|---|---|---:|
| 第 1 条 `[3, 0]` | $3\times2+0\times(-1)$ | 6 |
| 第 2 条 `[0, 2]` | $0\times2+2\times(-1)$ | -2 |
| 第 3 条 `[2, 1]` | $2\times2+1\times(-1)$ | 3 |

这说明：**每条评论的分数，就是它的特征和权重做点积。**

## 三、矩阵乘法：一次算完

一条一条算太慢了。NumPy 可以一行算完所有评论：

```python
scores = X @ w
print(scores)
```

```text
[ 6 -2  3]
```

`@` 是 Python 里专门表示矩阵乘法的运算符。它做的事情就是：**让 `X` 的每一行分别和 `w` 做点积**，每行得到一个分数。

完整跑一遍：

```python
import numpy as np

X = np.array([
    [3, 0],
    [0, 2],
    [2, 1]
])

w = np.array([2, -1])

scores = X @ w

print("矩阵形状:", X.shape)
print("权重形状:", w.shape)
print("预测分数:", scores)
```

```text
矩阵形状: (3, 2)
权重形状: (2,)
预测分数: [ 6 -2  3]
```

这些分数只是我们手动设权重算出来的，不是训练好的模型。真正训练时，权重要从数据里学出来，这是后面的课要讲的。

## 四、形状规则

数学里的矩阵乘法有两条规则：

$$
(3\times2)(2\times1)=(3\times1)
$$

- **中间的数字必须相同**，否则不能相乘
- **结果保留外侧的数字**

用数字写出来就是：

$$
Xw=
\begin{bmatrix}
3&0\\
0&2\\
2&1
\end{bmatrix}
\begin{bmatrix}
2\\
-1
\end{bmatrix}
=
\begin{bmatrix}
6\\
-2\\
3
\end{bmatrix}
$$

中间对不上会直接报错。比如 `(2, 4)` 的矩阵去乘 `(3, 2)` 的矩阵：

```text
ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0, with gufunc signature (n?,k),(k,m?)->(n?,m?) (size 3 is different from 4)
```

还有一点和普通乘法不一样：矩阵乘法**不能随便交换顺序**，$AB \ne BA$。有时 $AB$ 能算，$BA$ 根本算不了。

## 五、为什么结果是 `(3,)`，不是 `(3, 1)`

数学上 `(3×2)` 乘 `(2×1)` 应该得到 `(3×1)` 的列向量，可 NumPy 给的是 `(3,)`。

原因在 `w`。`np.array([2, -1])` 是一个**一维数组**，形状 `(2,)`，就是 2 个数，没有「行」和「列」的身份。一维数组和矩阵相乘，结果也是一维的。

想严格对应数学里的列向量，要把 `w` 写成二维：

```python
w = np.array([
    [2],
    [-1]
])

scores = X @ w
print(w.shape)
print(scores.shape)
print(scores)
```

```text
(2, 1)
(3, 1)
[[ 6]
 [-2]
 [ 3]]
```

| 左边 | 右边 | 结果 |
|---|---|---|
| `(3, 2)` | `(2,)` | `(3,)` |
| `(3, 2)` | `(2, 1)` | `(3, 1)` |
| `(3, 2)` | `(2, 4)` | `(3, 4)` |

记住：**`(n,)` 和 `(n, 1)` 装的数字一样，但维度结构不同**，后面的运算会受影响。

## 六、光看打印，分不清形状

`[ 6 -2  3]` 到底是 `(3,)` 还是 `(1, 3)`？只看数字分不清，要看方括号有几层，最可靠的是直接查 `shape`：

```python
a = np.array([6, -2, 3])
b = np.array([[6, -2, 3]])
c = np.array([[6], [-2], [3]])

for name, arr in [("a", a), ("b", b), ("c", c)]:
    print(name, "shape =", arr.shape, "ndim =", arr.ndim)
```

```text
a shape = (3,) ndim = 1
b shape = (1, 3) ndim = 2
c shape = (3, 1) ndim = 2
```

`a` 打印出来是 `[ 6 -2  3]`，一层方括号；`b` 是 `[[ 6 -2  3]]`，两层。`ndim` 是维度的个数。`(3,)` 里那个逗号不是漏了一个数，而是 Python 写只有一个元素的元组的方式。

最后提醒一个容易混的地方：`@` 是矩阵乘法，`*` 是对应位置相乘，两者完全不同。

## 八、小测

**1.** 已知 `X.shape = (5, 3)`，`w.shape = (3,)`。执行 `X @ w` 后，结果有多少个分数？

- A. 3 个
- B. 5 个
- C. 15 个

**2.** 已知 `x = np.array([4, 2])`，`w = np.array([3, -2])`，`x @ w` 的结果是多少？

- A. 8
- B. 16
- C. 12
- D. 4

**3.** 评论示例里权重是 `w = [2, -1]`。如果一条评论的特征是 `[1, 3]`，它的分数是多少？

- A. 5
- B. -1
- C. 1
- D. -5

<details>
<summary>答案</summary>

1. B。`X` 有 5 行，每行和 `w` 做一次点积，得到 5 个分数，形状 `(5,)`。
2. A。$4\times3+2\times(-2)=12-4=8$。
3. B。$1\times2+3\times(-1)=2-3=-1$。负面特征的贡献更大，所以分数是负的。

</details>

## 讲评（10-20）

三题你选了 B、A、B，全对。矩阵乘法的结果形状、点积、正负权重的作用，这三件事你都掌握了。

做题之前你自己写了 `NumPyDemo2.py`，打印出 `(3,)` 和 `(3, 2)`，然后连着追问：为什么是 `(3,)`；二维乘一维是不是得到一维；数学里的矩阵乘法怎么算；`[ 6 -2  3]` 怎么判断是 `(3,)` 还是 `(1, 3)`。这四个问题问的都是**形状**而不是数值，方向是对的。后面写模型代码，大部分报错和不报错却算错的情况，都出在形状上。养成一个习惯：写一行矩阵运算，就打印一次 `shape`。
