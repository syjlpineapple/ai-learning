# 第 16 课：计算机如何理解文字？

上一课你亲手写出了完整的训练循环：算预测、算损失、算梯度、更新权重，$w$ 一步步走向 3。你已经能把梯度下降写成代码了，再往下堆数学公式不划算。今天开始接触真正的 NLP 数据。

今天只回答一个问题：**一句话怎么变成数字？**

## 一、为什么文字需要转换成数字？

想象你给计算机一句话：

> 我喜欢 NLP

你一眼就懂。但前面学的点积、矩阵乘法、梯度下降，处理的全是数字。模型要处理文字，第一步就得先把文字变成数字。

这件事分两步走：

| 步骤 | 结果 |
|---|---|
| 原始文字 | 我喜欢 NLP |
| 切分成 Token | 我 ｜ 喜欢 ｜ NLP |
| 映射成词 ID（示例编号） | 17 ｜ 42 ｜ 105 |

这里的编号是随手举的，只为说明原理，不是哪个真实模型用的编号。

## 二、什么是 Token？

**Token（词元）** 是文本经过分词器处理后得到的基本单位。

Token 不一定是一个完整的词。不同的分词器，切出来的可能是：

- 一个完整的词，例如 `hello`
- 一个词的一部分，例如 `play` 和 `ing`
- 一个汉字，或者几个汉字组成的片段
- 标点符号，例如 `!`

比如一个简单的分词器可能把 `I love NLP!` 切成：

`["I", "love", "NLP", "!"]`

换一个模型，切法可能就不一样。

## 三、什么是词 ID？

词 ID 是分词器给每个 Token 分配的整数编号。

假设我们自己建一个最小的词表：

| Token | ID |
|---|---:|
| 我 | 0 |
| 喜欢 | 1 |
| NLP | 2 |

那么「我喜欢 NLP」就可以写成 `[0, 1, 2]`。

记住：**ID 本身不是词的含义。** 编号 2 不代表 NLP 比编号 1 的词更重要，两个编号之间也没有数学上的大小关系。它就像学号，只用来区分谁是谁。

## 四、动手写 Python

```python
text = "我 喜欢 NLP"

# 简化示例：按空格切分
tokens = text.split()

# 建立一个简单的词表
vocab = {
    "我": 0,
    "喜欢": 1,
    "NLP": 2
}

# 把 Token 转换为 ID
token_ids = [vocab[token] for token in tokens]

print("Tokens:", tokens)
print("Token IDs:", token_ids)
```

输出：

```text
Tokens: ['我', '喜欢', 'NLP']
Token IDs: [0, 1, 2]
```

注意 `text` 里我手动加了空格，`split()` 才能切开。中文词与词之间本来没有空格，真实的中文处理要用专门的分词工具，这个到第 27 课会遇到。今天先用空格绕过去，把注意力放在「文字变编号」这件事上。

## 五、小测

**1.** Token 一定是一个完整的词吗？

- A. 是，一定是完整的词
- B. 不一定，也可能是词的一部分或标点符号
- C. Token 只能是数字

**2.** 如果词表规定「猫」的 ID 是 8，这代表什么？

- A. 猫的重要程度是 8
- B. 猫的意思是数字 8
- C. 这个词在该词表中对应编号 8

**3.** 为什么 NLP 模型通常需要先把文本转换成数字？

- A. 因为模型需要数值表示才能进行后续的数学运算
- B. 因为数字一定比文字更有意义
- C. 因为转换后就不需要训练模型了

<details>
<summary>答案</summary>

1. B。Token 可以是完整的词，也可以是词的一部分、汉字片段或标点。
2. C。ID 只是编号，不表示重要程度，也不表示含义。
3. A。点积、矩阵乘法这些运算只认数字。

</details>

下一课我们看看：既然 ID 只是编号，说不出词的意思，那模型靠什么理解「猫」和「狗」比较像？
