# 第 18 课：如何计算两个词的相似度？

上一课你看到，猫 `[0.8, 0.7, 0.1]` 和狗 `[0.7, 0.8, 0.2]` 的数字很接近，汽车 `[0.1, 0.2, 0.9]` 很不一样。但「很接近」只是眼睛看出来的。今天我们把它变成一个能算出来的数字。

## 一、先用生活中的例子理解

还是猫、狗、汽车这三个词。

如果词向量学到了一部分语义关系，那么：

- **猫 vs 狗**：预期比较接近，都是常见的动物
- **猫 vs 汽车**：预期差异更大，一个是动物，一个是交通工具

注意，这只是直觉上的预期。真实模型算出来的相似度，取决于它学到的表示和训练任务，不保证每次都符合人的直觉。

## 二、什么是余弦相似度？

最常用的一种算法叫**余弦相似度（Cosine Similarity）**。先不看公式，先记住它的核心：

**它比较的是两个向量的方向有多接近，而不是数字有多大。**

把两个向量想成从原点出发的两支箭。两支箭指的方向越一致，余弦相似度越接近 1。

余弦相似度的取值范围是 -1 到 1：

| 相似度 | 大致含义 |
|---:|---|
| 接近 1 | 方向相近 |
| 接近 0 | 方向接近垂直 |
| 接近 -1 | 方向相反 |

在 NLP 里，相似度高有时说明两个词的意思或用法相近，但具体怎么解释，要看模型是怎么训练的。

## 三、用 Python 自己算一次

先用两个简单的二维向量练习：

- 向量 A：`[1, 0]`
- 向量 B：`[0.9, 0.1]`

公式是：

$$
\text{similarity}=\frac{A\cdot B}{\lVert A\rVert \, \lVert B\rVert}
$$

一个符号一个符号看：

- $A\cdot B$：两个向量对应位置相乘再求和，也就是**点积**。你在最开始的 NumPy 练习里用 `np.dot` 算过它。
- $\lVert A\rVert$：向量 A 的长度。
- $\lVert B\rVert$：向量 B 的长度。

为什么要除以两个长度？因为点积会被向量的长短影响，除掉长度以后，剩下的就只有方向了。

```python
import numpy as np

A = np.array([1.0, 0.0])
B = np.array([0.9, 0.1])

# 计算点积
dot_product = np.dot(A, B)

# 计算两个向量的长度
length_A = np.linalg.norm(A)
length_B = np.linalg.norm(B)

# 计算余弦相似度
similarity = dot_product / (length_A * length_B)

print("余弦相似度：", similarity)
```

输出：

```text
余弦相似度： 0.9938837346736189
```

结果非常接近 1，说明两个向量的方向非常接近。

## 四、动手比较不同的向量

把 A 固定为 `[1, 0]`，B 换成 `[1, v]`，让 `v` 慢慢变大，B 这支箭就会越来越往上翘。我用上面的公式算了几组：

| B | 余弦相似度 |
|---|---:|
| `[1, 0]` | 1.000 |
| `[1, 0.1]` | 0.995 |
| `[1, 0.5]` | 0.894 |
| `[1, 1]` | 0.707 |
| `[1, 2]` | 0.447 |
| `[1, 5]` | 0.196 |

第二个数字越大，B 的方向偏得越多，和 A 的相似度就越低。

你也可以把表里任意一行代进上面的代码，自己验算一遍。这只是数学上的二维例子，不是真实模型给两个词打的分。

## 五、小测

**1.** 余弦相似度主要比较什么？

- A. 两个向量的方向有多接近
- B. 两个向量各有多少个数字
- C. 两个向量中最大的数字是多少

**2.** 两个非零向量方向相同，它们的余弦相似度是多少？

- A. -1
- B. 0
- C. 1

**3.** 如果两个词向量的余弦相似度很高，我们应该怎样理解？

- A. 两个词在所有场景下都完全同义
- B. 在当前向量表示下，它们的方向比较接近，但不一定完全同义
- C. 两个词的 Token ID 一定相同

<details>
<summary>答案</summary>

1. A。比的是方向，不是数字个数，也不是最大值。
2. C。记住三个关键值：1 方向相同，0 相互垂直，-1 方向相反。
3. B。比如「苹果」和「手机」常出现在相似的句子里，相似度可能很高，但它们不是同一个概念。

</details>

## 讲评（10-23）

你交的是 **A、C、B**，三题全对。

你在 `day_6.py` 里把这段代码写了一遍，最后一行换成了 `print(f"余弦相似度：{similarity:.4f}")`，输出 `余弦相似度：0.9939`。`:.4f` 保留四位小数，比直接打印一长串好读，这个写法以后会经常用到。

第 3 题最容易想偏。相似度说的是「在这套向量里离得近」，不是「意思一样」。表示方法决定了它能捕捉到什么，这一点下一课讲词袋时会更明显。
