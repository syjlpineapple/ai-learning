# 第 17 课：词向量（Word Embeddings）

上一课你已经会把「我喜欢 NLP」变成 `[0, 1, 2]` 了，也记住了一点：ID 只是编号，不代表含义。

那问题就来了：只有编号，模型怎么知道「猫」和「狗」比较像，和「汽车」不像？今天就解决这个问题。先建立直觉，不需要复杂数学。

## 一、为什么词 ID 还不够？

假设词表里有三个词：

| 词语 | 词 ID |
|---|---:|
| 猫 | 8 |
| 狗 | 25 |
| 汽车 | 12 |

只看 ID，计算机不知道猫和狗都是动物，也不知道它们比较相似。

而且猫是 8、狗是 25，并不代表狗比猫「大」，也不代表它们的意思相差 17。汽车的 12 反而离猫更近，这显然没有道理。

这说明：**词 ID 的作用是标识词语，不是描述词语的含义。**

## 二、词向量是什么？

**词向量（Word Embedding）** 就是用一组数字来表示一个 Token，让模型能通过这些数字学到词语之间的关系。

看一个例子（数字是为了教学编的，不是真实模型的词向量）：

| 词 | 第 1 维 | 第 2 维 | 第 3 维 |
|---|---:|---:|---:|
| 猫 | 0.8 | 0.7 | 0.1 |
| 狗 | 0.7 | 0.8 | 0.2 |
| 汽车 | 0.1 | 0.2 | 0.9 |

每个词对应三个数字，每一列叫一个**维度**。

你可以看到，猫和狗的三个数字很接近，汽车的就完全不一样。这一次，「像不像」终于能从数字里看出来了。

真实模型的词向量通常有几十、几百甚至更多维。每个维度一般说不清具体代表什么，这些数字是模型通过训练学出来的。

## 三、用 Python 看看区别

```python
# 词 ID：一个编号
token_ids = {
    "猫": 8,
    "狗": 25,
    "汽车": 12
}

# 教学用词向量：一组数字
embeddings = {
    "猫": [0.8, 0.7, 0.1],
    "狗": [0.7, 0.8, 0.2],
    "汽车": [0.1, 0.2, 0.9]
}

print("猫的 ID：", token_ids["猫"])
print("猫的向量：", embeddings["猫"])
```

输出：

```text
猫的 ID： 8
猫的向量： [0.8, 0.7, 0.1]
```

把这两个概念放在一起对比：

| 概念 | 作用 | 形式 |
|---|---|---|
| Token ID | 标识 Token | 一个整数 |
| 词向量 | 为 Token 提供可学习的数值表示 | 一组数字 |

## 四、词向量是怎么学出来的？

这就和你前面学的训练过程接上了。一句话进入模型，大致经过这几步：

1. **文字**：「我喜欢猫」
2. **分词与 Token ID**：把文本转换成编号
3. **Embedding 层**：根据编号，取出对应的那一行向量
4. **模型计算与训练**：根据训练目标调整模型参数

关键在第 4 步：**词向量通常也是模型的可训练参数。** 训练时，模型会像更新第 15 课的 $w$ 那样，根据损失一点点调整这些向量。所以 ID 只负责「查表」，向量才负责「表达意思」。

不是所有模型都用同一种训练方式。现代大型语言模型还会用注意力机制等结构，根据上下文动态处理 Token，这些以后再学。

## 五、小测

**1.** 词 ID 为 8，代表什么？

- A. 这个词有 8 个维度
- B. 这个词在词表中对应编号 8
- C. 这个词比 ID 为 25 的词更重要

**2.** 词向量最主要的特点是什么？

- A. 用一组数字表示 Token，供模型进一步学习和计算
- B. 每个词只能对应一个整数
- C. 词向量永远不能被训练改变

**3.** 在模型训练过程中，词向量通常会怎样？

- A. 所有词向量都必须保持不变
- B. 所有词向量都必须变成 0
- C. 可训练的词向量会根据训练目标进行调整

<details>
<summary>答案</summary>

1. B。ID 只是编号，和维度、重要程度都没有关系。
2. A。一个整数只能区分谁是谁，一组数字才能描述「像不像」。
3. C。补充一点：有些模型会把词向量「冻结」住不训练，所以不是所有任务里词向量都会变。

</details>

## 讲评（10-22）

你交的是 **B、A、C**，三题全对。

从第 16 课到这一课，你已经分清了两件事：ID 管「是谁」，向量管「像谁」。这节课是纯概念课，没有作业代码。表里那几个数字你也可以自己看一下：猫和狗每一维都只差 0.1，猫和汽车每一维都差得很远。下一课会把这种「看起来像」变成一个能算出来的分数。
