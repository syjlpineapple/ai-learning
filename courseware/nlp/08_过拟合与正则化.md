## 本节掌握

- **训练集准确率**是什么：用训练完的模型回头预测训练集
- **过拟合（Overfitting）**：训练好、测试差；考试死记硬背的类比
- **欠拟合 / 合适拟合 / 过拟合**三种状态怎么区分
- **泛化能力（Generalization）**
- 用 `train_acc - test_acc` 的 **gap** 观察过拟合
- **正则化**：在损失里加一项惩罚，约束权重大小
- **L2 正则化**公式 $总损失 = 原始损失 + \lambda\sum w_i^2$
- **`C` 和正则化强度是反向关系**：C 越小，正则化越强
- `LogisticRegression` **默认就带 L2 正则化**
- **L1 与 L2 的机制差异**：L1 让权重变成 0，L2 只让它变小
- `np.linalg.norm(model.coef_)` 看权重整体大小
- **模型复杂度**、**偏差（Bias）与方差（Variance）**
- **权重变了 ≠ 预测变了**：这是这三课最核心的现象
- **实测发现一**：L2 等比例缩放权重，**不改变决策边界的方向**，所以预测永远不变

## 2. 「训练集准确率」到底是什么

这是当时问出的一个好问题：

```
2026-11-11 15:36  训练集准确率99%是什么意思，是用训练集训练后的到的模型又来预测训练集的意思吗
```

**正是这个意思。**

```python
model.fit(X_train, y_train)              # ① 用训练集学

train_pred = model.predict(X_train)      # ② 回头预测训练集
y_pred = model.predict(X_test)           # ③ 预测测试集

train_acc = accuracy_score(y_train, train_pred)
test_acc = accuracy_score(y_test, y_pred)
```

**第 ② 步看起来多余——答案模型都见过了，为什么还要再问一遍？**

因为这是**诊断**，不是评估。它回答的是「模型连自己背过的题都做不对吗」：

| 训练集准确率 | 说明 |
|---|---|
| **低**（比如 55%） | 模型连训练数据都拟合不了 → **能力不足或约束太强**（欠拟合） |
| **高**（比如 100%） | 模型至少有能力记住训练数据 → 再看测试集决定是「学会了」还是「背下来了」 |

**单独看训练集准确率没有意义，它必须和测试集准确率配对看。** 这就是下面的 gap。

## 3. 过拟合

### 考试的类比

| 学习方法 | 对应 |
|---|---|
| **方法 A**：理解知识点，能解不同类型的题 | 学到了规律 |
| **方法 B**：只背练习册上的 100 道题，题目一改就不会 | **过拟合** |

映射到机器学习：

```text
训练集  =  平时的练习题
测试集  =  没见过的考试题
过拟合  =  练习题全对，考试题不会做
```

**定义**：模型把训练数据记得太熟，却没有学到能推广到新数据的规律。

`course_30.py` 开头的注释就是这句话（原样保留，错别字也留着）：

```python
"""
第30课：模型优化与过拟合
过拟合： 模型吧训练数据记得很熟，但是没有真正学会可以推广到新评论的规律
"""
```

### 三种状态

| 状态 | 训练集 | 测试集 | 什么情况 |
|---|---|---|---|
| **欠拟合 Underfitting** | 差 | 差 | 模型**没学会** |
| **合适拟合 Good Fit** | 好 | 好 | 模型**学会了规律** |
| **过拟合 Overfitting** | 很好 | 差 | 模型**背下来了** |

**注意「欠拟合」的特征是两边都差。** 这一点在后面的 L1 实验里会直接看到。

### 泛化能力

**泛化能力（Generalization）**：模型面对没见过的新数据时仍能正确预测的能力。

> 训练模型不是为了让它记住训练集，而是希望它能处理现实中不断出现的新数据。
> **这也是必须保留测试集的理由。**

## 4. 怎么观察：gap

```python
gap = train_acc - test_acc
```

| 情况 | 训练集 | 测试集 | gap | 判断 |
|---|---:|---:|---:|---|
| A | 55% | 50% | 5% | 可能**欠拟合**（两边都低） |
| B | 90% | 85% | 5% | **泛化较好** |
| C | 99% | 55% | 44% | 可能**过拟合** |

**A 和 C 的 gap 都不大／都很大不是重点，重点是「两边的绝对水平」加上「差距」一起看：**

- 两边都低 → 欠拟合
- 两边都高 → 挺好
- 一高一低 → 过拟合的嫌疑

> gap 大只是**过拟合的嫌疑**，不是判决。小数据集上指标本身就在剧烈抖动——6 条测试样本，
> 错一条就是 16.7 个百分点。这一节第二部分会看到一个 gap 高达 83.3% 却**不是过拟合**的例子。

## 5. 正则化是什么

### 从权重说起

逻辑回归为每个特征学一个权重：

| 特征词 | 权重（示意） |
|---|---:|
| 好用 | +2.5 |
| 优秀 | +1.8 |
| 糟糕 | -2.2 |
| 很差 | -3.0 |

**权重绝对值越大，这个特征对预测的影响越大。**

如果模型为了把少量训练数据记牢，学出一堆特别大的权重，它就变得「过于自信、过于复杂」——某个只在一条训练样本里出现过的词，可能被赋予很大的权重。

**正则化就是对权重的大小施加约束。**

### 换个比喻

| | 对应的学生 |
|---|---|
| 不加正则化 | 拼命记住每道练习题，连题干里的细节都背 |
| 加正则化 | 不许死记硬背，只能学更稳定、更有代表性的规律 |

**注意：正则化不保证准确率提高，它只是控制模型复杂度。** 这句话在第二部分会被实测狠狠印证。

## 6. L2 正则化

$$
总损失 = 原始损失 + \lambda\sum_i w_i^2
$$

| 项 | 含义 |
|---|---|
| 原始损失 | 预测错误造成的损失（逻辑回归里是交叉熵） |
| $\sum w_i^2$ | **所有权重的平方和**——权重越大，这一项越大 |
| $\lambda$ | 正则化强度，越大惩罚越重 |

**机制很直白**：模型想降低总损失，就得在「预测得准」和「权重别太大」之间权衡。原来它可以无代价地把某个权重拉到 10，现在要为此付出 $100\lambda$ 的代价。

### 一个容易误解的点

> 你之前使用的 `LogisticRegression` **默认就采用 L2 正则化**，并不是完全没有正则化。

```python
LogisticRegression()                   # 等价于 penalty='l2', C=1.0
```

**第 28-29 课那些模型全都已经带着 L2 正则化在跑了。** 第 31 课做的不是「加上正则化」，而是**调整它的强度**。

## 7. `C` 参数：反向关系

sklearn 不直接暴露 $\lambda$，而是用 `C`：

$$
C = \frac{1}{\lambda}
$$

| `C` | 正则化强度 |
|---|---|
| `C=100` | 很弱 |
| `C=10` | 较弱 |
| **`C=1`** | **默认** |
| `C=0.1` | 较强 |
| `C=0.01` | 更强 |

**`C` 越小，正则化越强；`C` 越大，正则化越弱。**

这个反向关系很容易记错。记法：**`C` 可以理解成「给模型的自由度」**——C 大，模型自由，权重可以很大；C 小，模型被管得严，权重被压小。

> 第 31 课的小测考的正是这个：「希望增强 L2 正则化，应该怎么调整 C？」
> 答案 **A. 减小 C，例如从 1 改为 0.1** ✅

## 8. 怎么观察正则化生效了：权重范数

```python
weight_norm = np.linalg.norm(model.coef_)
```

`np.linalg.norm` 算的是向量长度（第 05 节算余弦相似度时用过）：

$$
\|w\| = \sqrt{\sum_i w_i^2}
$$

**它把所有权重压成一个数字，用来看「权重整体有多大」。**

正则化增强（C 变小）→ 权重被压小 → 范数变小。这是验证正则化是否生效的直接指标，比看准确率可靠得多——**因为准确率可能根本不动**。

## 9. L1 与 L2：机制不同，不是强弱不同

| | L1（Lasso） | L2（Ridge） |
|---|---|---|
| 惩罚项 | $\lambda\sum \lvert w_i \rvert$ | $\lambda\sum w_i^2$ |
| 对权重的作用 | **让一部分权重变成 0** | 让权重变小，但**通常不为 0** |
| 效果 | **特征选择**（稀疏化） | 整体收缩 |

**为什么 L1 会把权重精确压到 0？**

因为 $\lvert w \rvert$ 的梯度在 0 附近是常数 $\pm\lambda$，不随 $w$ 变小而减弱——它会持续把权重往 0 推，直到撞上 0 就停在那儿。而 $w^2$ 的梯度是 $2w$，$w$ 越小推力越弱，**越接近 0 越推不动**，所以只会无限趋近而不等于 0。

sklearn 里切换：

```python
LogisticRegression(penalty="l1", C=1, solver="liblinear")
LogisticRegression(penalty="l2", C=1, solver="liblinear")
```

**`solver="liblinear"` 是必须的**——默认的 `lbfgs` 不支持 L1。

| 什么时候用 | |
|---|---|
| **L1** | 特征很多、怀疑大部分无用，想让模型自动挑特征 |
| **L2** | 特征都可能有点用，只想防止任何一个权重过大（**默认选它**） |

> **L1 不是「更强的 L2」。** 同样的 `C`，两者的后果可能天差地别——
> 第二部分的实测里，`C=1` 下 L2 完好无损，L1 **把 37 个权重全部清零**。

## 10. 模型复杂度、偏差与方差

### 模型复杂度

**模型学习和表达复杂规律的能力。**

| 模型 | 复杂度 |
|---|---|
| 只根据「好」「差」两个词判断 | 低 |
| 根据更多词语及其组合判断 | 中 |
| 使用大量特征，试图记住每条评论的细节 | 高 |

**复杂度越高，表达能力越强，过拟合风险也越大。** 正则化的作用就是在训练过程中压制复杂度。

### 偏差与方差

| 概念 | 简单理解 | 常见表现 |
|---|---|---|
| **Bias（偏差）** | 模型太简单，学不到规律 | **欠拟合** |
| **Variance（方差）** | 模型对训练数据的变化过于敏感 | **过拟合** |

记法：**高偏差 = 学得不够；高方差 = 学得太过头。**

「方差大」的具体含义是：换一批训练数据，模型学出来的东西会大变。**第 07 节那个「电池」权重 +0.427 就是高方差的典型** ——换一批不含「电池非常耐用」的训练数据，这个权重会完全不同。

### 目标不是训练集 100%

| 模型 | 训练准确率 | 测试准确率 | 判断 |
|---|---:|---:|---|
| A | 65% | 62% | 可能欠拟合 |
| B | **90%** | **86%** | **泛化较好** |
| C | 100% | 55% | 可能严重过拟合 |

**B 比 C 好，尽管 C 的训练准确率更高。** 要的是对新数据的表现，不是训练集上的满分。

## 11. 核心现象：权重变了 ≠ 预测变了

这是第 31、32 课最反直觉、也最该记住的一点。

**要区分两件事：**

| | 变了吗 |
|---|---|
| ① 模型**参数**（权重）变化 | 正则化一定会改变它 |
| ② 模型**预测结果**变化 | **不一定** |

因为分类结果只取决于**概率有没有跨过 0.5**：

| C | 判断分数（示意） | 概率 | 预测 |
|---:|---:|---:|---:|
| 10 | -2.5 | 0.076 | 差评 |
| 1 | -0.8 | 0.310 | 差评 |
| 0.1 | -0.12 | 0.470 | 差评 |
| 0.01 | -0.01 | 0.498 | 差评 |

**分数一路往 0 靠，但始终没有跨过边界，所以预测标签从头到尾是 0。**

这解释了「权重从 6.92 降到 0.0166，准确率一动不动」的现象：**正则化改变的是模型有多自信，不一定改变它的判断。**

> 所以观察正则化效果**不能只看准确率**，要同时看：
> 权重范数（参数变了吗）、预测概率（自信度变了吗）、预测标签（判断变了吗）。
> 第二部分会看到一个更极端的版本：C 跨 10 个数量级，**预测标签一个都没变。**

## 第 31 课：`course_31.py` —— 「为啥准确率没变」

代码扫了四个 `C`，并加上权重范数：

### 实测复现

我把 `C` 扩到六个值重跑，结果和当时完全一致：

| C | 训练 acc | 测试 acc | gap | **权重范数** | 预测标签 |
|---:|---:|---:|---:|---:|---|
| 0.001 | 1.0000 | 0.1667 | 0.8333 | **0.0017** | `[1,0,1,0,1,1]` |
| 0.01 | 1.0000 | 0.1667 | 0.8333 | **0.0166** | `[1,0,1,0,1,1]` |
| 0.1 | 1.0000 | 0.1667 | 0.8333 | **0.1633** | `[1,0,1,0,1,1]` |
| 1 | 1.0000 | 0.1667 | 0.8333 | **1.4080** | `[1,0,1,0,1,1]` |

概率确实在动：

```text

C=0.01    [0.5005 0.499  0.5005 0.4993 0.5013 0.5007]
C=0.1     [0.5041 0.4895 0.5039 0.4928 0.5116 0.5062]
C=1       [0.5319 0.4166 0.5308 0.4454 0.5926 0.5503]
C=10      [0.5999 0.2105 0.6107 0.3149 0.811  0.6887]
```

**所以代码没问题，「准确率不变」才是这个实验的结论。** 第 31 课的小测考的就是这个：

> C 从 10 下降到 0.01，权重明显变小，但预测标签和准确率都没变化，这说明什么？
> **A. 模型参数变化了，但还没有改变分类边界对这些样本的判断结果** ✅

### 实测追加：把 C 推到 1e-8

既然 C=0.001 时权重范数只剩 0.0017，再往下压会不会终于改变预测？

```text
C=0.0001   范数=1.664e-04  训练acc=1.0  测试acc=0.1667  预测=[1,0,1,0,1,1]
C=1e-05    范数=1.664e-05  训练acc=1.0  测试acc=0.1667  预测=[1,0,1,0,1,1]
C=1e-06    范数=1.664e-06  训练acc=1.0  测试acc=0.1667  预测=[1,0,1,0,1,1]
C=1e-08    范数=1.664e-08  训练acc=1.0  测试acc=0.1667  预测=[1,0,1,0,1,1]
```

**C 跨 10 个数量级（100 → 1e-8），预测标签一个都没变，训练集准确率还是 1.0。**

`C=1e-6` 时概率打印出来全是 `0.5`（小数位数不够显示差异），权重范数只有 0.0000016——**模型几乎没有权重了，却依然把 18 条训练样本全部分对。**

### 为什么 L2 怎么压都不改变预测

看范数的变化规律：

```text
C=1e-4 → 1.664e-04
C=1e-5 → 1.664e-05        ← 正好 1/10
C=1e-6 → 1.664e-06        ← 正好 1/10
```

**`C` 很小时，权重向量是等比例缩小的**（$w \propto C$），方向完全不变。

而线性分类器的预测只看 $w \cdot x + b$ 的**符号**：

$$
\text{sign}(k \cdot w \cdot x) = \text{sign}(w \cdot x) \qquad (k > 0)
$$

**所有权重同时缩小 $k$ 倍，符号不变，预测就不变。** 变的只有 $\lvert w \cdot x \rvert$ 的大小，也就是概率离 0.5 有多远——**自信度**。

| L2 正则化改变的 | L2 正则化不改变的 |
|---|---|
| 权重的**大小** | 权重的**方向** |
| 预测**概率**（自信度） | 决策**边界的朝向** |
| | **预测标签**（在这组数据上） |

> **这是一个很干净的数学事实，值得记住：** 在线性可分的数据上，
> L2 正则化主要调节模型的自信程度，不太会改变它的判断。
> 想让正则化改变分类结果，得是在那些「概率本来就贴着 0.5」的样本上——
> 而这组数据的六个概率在 `C=1` 时正好全贴在 0.42~0.60，所以它们一起平移，没有一个越界。

第 32 课把 `C` 扩到 `[0.001, 0.01, 0.1, 1, 10, 100]`，加了 gap 的打印。结果和第 31 课一样：六组全是 `100% / 16.67% / 83.33%`。

当时的结论：

以及一段很到位的补充：

> 你的训练集准确率始终 100%，即使 C 很小也没有下降。
> **这说明问题不一定只靠调整 C 就能解决。**

**后半句是对的，但「符合过拟合」这个判断站不住。** 下面是证据。

## 实测发现：这不是过拟合

过拟合的含义是「模型只记住了训练数据，没学到可推广的规律」。如果真是这样，**它在新数据上的表现应该接近随机猜**。

把这个推论算出来：

```text
测试集标签分布: {0: 3, 1: 3}        ← 完全平衡
全部预测 0 的准确率: 0.5
全部预测 1 的准确率: 0.5
随机猜的期望准确率: 0.5

模型实际: 0.1667                    ← 显著低于随机
```

**0.1667 不是「没学到」，是「学反了」。** 一个什么都不学、全部预测同一类的模型能拿 0.5，模型只拿了 0.17——**它比瞎猜差了整整 3 倍。**

决定性的一步验证——把模型的预测整体取反：

```text
把模型预测整体取反的准确率: 0.8333
```

**取反之后 83.3%。**

| | 准确率 |
|---|---:|
| 模型预测 | 0.1667 |
| 全预测同一类（基线） | 0.5000 |
| **模型预测取反** | **0.8333** |

一个「只是记住了训练集、对新数据毫无头绪」的模型不可能有这个性质。**取反能到 83% 说明模型稳定地学到了一个规律，只是这个规律在测试集上是反的。**

### 为什么会学反

第 07 节已经把证据查全了：

| 证据 | 内容 |
|---|---|
| 未登录词 | 6 条测试评论的**情感词全部不在训练词汇表**（`慢`、`不错`、`棒`、`模糊`、`很差`、`屏幕显示`） |
| 中性词被学成判别特征 | 「电池」权重 **+0.427**、「这个」权重 **-0.315** |
| 概率全贴 0.5 | `C=1` 时六个概率落在 0.42~0.60 |

模型能看到的只有中性词，而中性词的权重是从 18 条训练样本的**偶然分布**里学来的。这些偶然恰好在这 6 条测试样本上系统性地指向错误方向。

**诊断结论：**

| 诊断 | 成立吗 |
|---|---|
| 「训练好、测试差」 | ✅ 现象描述正确 |
| 「这是过拟合」 | ❌ **过拟合的测试表现应该≈随机（0.5），不是 0.17** |
| 真实情况 | **特征覆盖失效 + 虚假规律**。模型不是「记住了训练集」，而是**在测试集上根本看不到有用特征**，只能用一堆巧合权重做系统性错误的判断 |

> **这个区分很要紧，因为它决定了该吃哪副药。**
>
> | 如果是 | 该做的 |
> |---|---|
> | 过拟合 | 加正则化、减特征、加数据 |
> | **特征覆盖失效** | **补覆盖目标词汇的数据、改分词、换表示方法** |
>
> 诊断错了，就会像第 31、32 课那样——**在 `C` 上花两天，指标一动不动。**

## 实测发现：L1 在 `C=1` 时全军覆没

第 31 课最后设计了一个 L1 vs L2 的对比实验，代码里没有留下来。我补跑了一遍：

```text
penalty=l1  特征数=37  零权重=37 (100.0%)
  权重范数=0.0000  训练acc=0.5000  测试acc=0.5000

penalty=l2  特征数=37  零权重=0 (0.0%)
  权重范数=1.4077  训练acc=1.0000  测试acc=0.1667
```

**同样的 `C=1`，L1 把 37 个权重全部压成了 0。**

权重全为 0 意味着模型退化成只剩截距，**对所有输入给出同一个预测**。训练和测试准确率都变成 0.5——

**这就是「欠拟合」的活标本**，和第 10 小节那张表完全对上：

| 状态 | 训练集 | 测试集 | 这次实验 |
|---|---|---|---|
| **欠拟合** | **差** | **差** | **L1, C=1 → 0.50 / 0.50** ✓ |
| 合适拟合 | 好 | 好 | —— |
| 过拟合 | 很好 | 差 | L2, C=1 → 1.00 / 0.17 |

### 为什么 L1 这么激进

因为 **TF-IDF 的特征值本来就很小**。L2 归一化让每行向量长度为 1，单个特征值通常在 0.2~0.5 之间。L1 的惩罚项 $\lambda\lvert w \rvert$ 对权重施加一个恒定的「推向 0」的力，当特征提供的收益小于这个推力时，权重就被直接按到 0 并留在那里。

37 个弱特征 + 18 个样本，没有一个特征的收益能顶住 `C=1`（即 $\lambda=1$）的 L1 惩罚。

**所以 L1 配 TF-IDF 时，`C` 往往要设得比 L2 大得多**（比如 10 或 100），否则直接全清零。

> 这个结果印证了第 31 课的那句提醒：
> 「如果正则化太强，模型可能连真正有用的规律也学不到，这叫**欠拟合**。」
>
> 当时它是一句抽象的警告，实测之后它变成了一个具体数字：**37/37 个权重归零。**
>
> 也顺带说明 **L1 和 L2 不是「强弱」关系，而是机制不同**。
> `C=1` 对 L2 来说很温和，对 L1 来说是毁灭性的。

## 实测发现：调 C 无效，补数据有效

第 29 课本来设计过一个**控制变量**的 A/B 实验（测试集保持不变，只加训练数据），但实际没按这个做。我把它补上了：

```text
实验A 基线:  训练 18 条，词汇表 37
实验B 扩充:  训练 30 条，词汇表 54
（测试集保持原来那 6 条不变 —— 这才是控制变量的做法）
```

新增的 12 条样本刻意覆盖之前的未登录词（「很慢」「不错」「很强」「模糊」等）：

```python
extra_texts = [
    "手机运行速度非常流畅", "这款产品表现不错", "电池续航能力很强",
    "屏幕显示十分清楚", "拍照效果很出色", "使用起来非常满意",
    "手机运行速度太慢", "产品体验令人失望", "电池续航能力很弱",
    "屏幕显示非常糟糕", "拍照效果十分模糊", "手机使用体验很差",
]
extra_labels = [1] * 6 + [0] * 6
```

结果：

| 实验 | 训练 acc | 测试 acc | gap | **测试集未登录词总数** |
|---|---:|---:|---:|---:|
| **A 基线（18 条）** | 1.0000 | **0.1667** | 0.8333 | **7** |
| **B 扩充（30 条）** | 1.0000 | **0.3333** | 0.6667 | **2** |

**测试准确率翻倍（0.1667 → 0.3333），未登录词从 7 个降到 2 个，gap 从 0.83 降到 0.67。**

对比两种「优化」手段：

| 手段 | 幅度 | 测试准确率的变化 |
|---|---|---|
| 调 `C` | 跨 **10 个数量级**（100 → 1e-8） | **0.1667 → 0.1667**（完全不动） |
| 补训练数据 | **12 条** | **0.1667 → 0.3333**（翻倍） |

**这就是「先诊断再下药」的实证。** 根因是特征覆盖，所以补覆盖的数据有效，调约束强度无效。

### 但 0.3333 仍然很差——剩下的问题是什么

逐条看实验 B：

```text
[错] 手机运行速度很慢 真实0 预测1 概率0.5188 未登录['慢']
[错] 这个产品真的不错 真实1 预测0 概率0.4669 未登录[]
[对] 屏幕显示效果很好 真实1 预测1 概率0.5375 未登录[]
[错] 电池续航特别棒   真实1 预测0 概率0.4714 未登录['棒']
[错] 拍照效果非常模糊 真实0 预测1 概率0.5328 未登录[]
[对] 屏幕显示效果很差 真实0 预测0 概率0.4787 未登录[]
```

**两个新问题：**

**第一，补的词又没对上。** 我补的是「太慢」「很强」，而测试集切出来的是「慢」「棒」——**分词粒度不一致的问题还在**。补数据时我用了不同的措辞，jieba 切出的词就不同。

**第二，词进了词表也不一定预测对。** 「拍照效果非常模糊」的「模糊」这次在词表里了（补了「拍照效果十分模糊」），但依然预测错，概率 0.5328。**一个词只出现在 1 条训练样本里，学出来的权重撑不起判断。**

| 补数据要满足的条件 | 这次做到了吗 |
|---|---|
| 覆盖目标词汇 | 部分（7 → 2） |
| **分词后的词形要一致** | ❌ 「太慢」≠「慢」 |
| **每个判别词要有足够多的样本** | ❌ 多数词只出现 1 次 |

**所以这组实验的真正出路不是调参，也不只是加 12 条数据，而是：**

1. **加一个数量级的数据**（每类几百条，让每个情感词出现几十次）
2. **统一分词**（自定义词典，把「很慢」「太慢」「慢」规范到同一个词）
3. **换表示方法**（词向量 / 子词切分，让「棒」和「好」在向量空间里本来就接近）

> 第 3 条才是根本解法。TF-IDF 把每个词当成独立的、互不相关的维度，
> **「棒」和「好」在它眼里毫无关系**。只要用的是词表方法，未登录词和近义词问题就一直在。
> 这也是整条学习路线后面要走向 Embedding 和预训练模型的原因。

9. **反向关系**：$C = 1/\lambda$，C 越小正则化越强。记法：把 C 理解成「给模型的自由度」——C 大则自由、权重可以很大；C 小则管得严、权重被压小。
10. 算所有权重组成的向量的长度 $\sqrt{\sum w_i^2}$，把全部权重压成一个数。它更可靠是因为**准确率可能完全不动**（预测没跨过 0.5），而权重范数一定会随 C 变化——它直接证明参数变了。
11. L1 让一部分权重**精确变成 0**（特征选择／稀疏化），L2 让权重变小但通常不为 0。原因在梯度：$\lvert w \rvert$ 的梯度是常数 $\pm\lambda$，不随 $w$ 变小而减弱，会持续推到 0 为止；$w^2$ 的梯度是 $2w$，越接近 0 推力越弱，所以只能无限趋近。
12. 因为默认的 `lbfgs` 求解器**不支持 L1 惩罚**（L1 在 0 点不可导，需要专门的优化算法）。`liblinear` 同时支持 L1 和 L2。
13. **Bias（偏差）→ 欠拟合**（模型太简单，学不到规律）；**Variance（方差）→ 过拟合**（对训练数据变化过于敏感）。「方差大」的具体含义是：换一批训练数据，模型学出来的东西会大变——比如「电池」权重 +0.427 只是因为训练集里恰好有「电池非常耐用」是好评。
14. **不是，正则化生效了。** 权重范数变了 400 多倍就是证据。没变的是**预测标签**，因为概率虽然一路向 0.5 靠近，但始终没跨过 0.5 这条线。要区分「参数变了」和「判断变了」。
15. 因为 **C 很小时权重向量是等比例缩小的**（实测 1.664e-4 → 1.664e-5 → 1.664e-6，正好是 1/10），方向完全不变。线性分类器的预测只取决于 $w \cdot x + b$ 的**符号**，而 $\text{sign}(k \cdot w \cdot x) = \text{sign}(w \cdot x)$ 对任何 $k>0$ 都成立。所以缩放不改变预测，只改变概率离 0.5 有多远。
16. **改变**了权重的大小、预测概率（自信度）；**没改变**权重的方向、决策边界的朝向，以及（在这组数据上）预测标签。
17. **显著差。** 3:3 平衡下，全部预测同一类就能拿 0.5，随机猜的期望也是 0.5。模型只有 0.1667，**比瞎猜差了 3 倍**。
18. **学到了反向规律。** 一个「没学到规律」的模型在新数据上应该接近随机（0.5）；取反能到 83.3% 说明模型的判断是**系统性、稳定地**指向错误方向，而不是毫无头绪。
19. 因为过拟合的典型测试表现是**接近随机（0.5）**，而这里是 0.17 且取反能到 0.83。真实情况是**特征覆盖失效 + 虚假规律**：6 条测试评论的情感词全部未登录，模型只能用「电池」「这个」这类中性词的巧合权重做判断。诊断错的后果是**吃错药**——在 `C` 上调两天指标一动不动，而正确的药是补覆盖目标词汇的数据、改分词、换表示方法。
20. **欠拟合。** 权重全为 0 意味着模型退化成只剩截距，对所有输入给出同一个预测，训练和测试都是 0.5——完全符合「欠拟合 = 两边都差」的定义。
21. 因为 TF-IDF 经过 L2 归一化后每行长度为 1，**单个特征值很小**（通常 0.2~0.5）。L1 对每个权重施加恒定的「推向 0」的力，当特征提供的收益小于这个推力时权重就被按到 0。37 个弱特征配 18 个样本，没有一个能顶住 `C=1` 的 L1 惩罚。所以 L1 配 TF-IDF 时 `C` 要设得比 L2 大得多。
22. **补数据。** 调 `C` 跨 10 个数量级（100 → 1e-8）准确率**完全不动**（0.1667）；补 12 条覆盖目标词汇的数据，准确率**翻倍到 0.3333**，未登录词从 7 个降到 2 个，gap 从 0.83 降到 0.67。
23. **一、补的词形又没对上**：补的是「太慢」「很强」，测试集切出的是「慢」「棒」——分词粒度不一致的问题还在。**二、词进了词表也不够**：「模糊」这次在词表里了但仍预测错，因为它只出现在 1 条训练样本里，权重撑不起判断。
24. 三条：**加一个数量级的数据**（让每个情感词出现几十次）、**统一分词**（自定义词典规范词形）、**换表示方法**（词向量／子词切分）。第三条是根本解法，因为 **TF-IDF 把每个词当成独立互不相关的维度，「棒」和「好」在它眼里毫无关系**——只要用词表方法，未登录词和近义词问题就一直存在。这也是后面要走向 Embedding 和预训练模型的原因。
