# AI 应用开发

按当时定下的 90 天路线走（11-17 根据「测试占比过重」调整过一次）：先把 Python 写扎实，再学网络请求和配置，然后是大模型 API、RAG 知识库、Agent，最后做一个能部署、能演示的完整应用。一天一页，约 45 分钟，编号和当时跟 ChatGPT 学的 Day N 一致。

**一天的顺序**：讲概念 → 演示（代码和真实输出）→ 今天的作业 → 小测。作业写在仓库根目录的 `dailypractice/DayNN/`，写完把输出发给我，讲评追加到那一天的末尾。Day 11-22 后面挂的「加练」是另外出的选做题，带测试，可以不做。

课文在 `courseware/ai/` 下，一个阶段一个文件夹，不开网站也能直接在编辑器里看，课表是 `ai/README.md`。
