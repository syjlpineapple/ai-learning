# NLP 算法工程师

按当时定下的 48 周路线走（11-13 加进了 RAG 专项）：数学和文本向量化打底，传统机器学习做文本分类，再到词向量与语义搜索、PyTorch、Transformer 微调，最后是 RAG 和求职准备。一路做出四个作品：中文文本分类器、中文语义搜索、Transformer 文本分类、企业知识库 RAG。一课一页，约 45 分钟，编号和当时跟 ChatGPT 学的第 N 课一致。

<CourseRun course="nlp" />

**一课的顺序**：讲概念（公式拆开讲，先用小数字和生活里的例子）→ 演示 → 今天的实验任务 → 小测。代码写在仓库根目录的 `nlp/courseNN/`，运行后把输出发给我，讲评追加到那一课的末尾。第 1-33 课暂时只有当时学习记录的整理（每个阶段下面的「学习记录」），之后会拆成一课一页。

课文在 `courseware/nlp/` 下，一个阶段一个文件夹，不开网站也能直接在编辑器里看，课表是 `nlp/README.md`。
